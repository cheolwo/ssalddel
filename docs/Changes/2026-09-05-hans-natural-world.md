# 한스 농장·인접 숲 구조 조립 후보

- 상태: 커밋 전, 시각 승인 Pending, E 승격 없음.
- 변경: 기존 Graph Map·배치 프로필 결속, 실제 손상 주택 자산·작업 공간·밭·울타리·연속 흙길·식생 조립, 원거리 후보 지면 보존, 수리 울타리 외형 축 보정.
