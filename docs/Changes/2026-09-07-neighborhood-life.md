# 가상 동네 직업 생활 · 30분

기존 도형 동네에 서쪽 보충창고, 화물차, 창고/주민/음식점 주체, 하역·별도 정차점, 물품 표현과 정책 카드를 추가했다. 음식점 빨강·주문자 파랑·창고 하양·기사 검정을 유지한다. 30분 전용 프로필에서 NPC별 따라보기, 재고·대기 사유·근무/휴식을 조회한다.

검증 수준: 코드·자동 시험 및 실제 Play Runtime 조회. Game View/버튼 입력·문자 판독·시각 마감은 미검증이다. PNG 없이 실제 화면 검증 완료로 표시하지 않는다. Scene 파일은 저장하지 않았다. 저장 호환·서버 초기화 분리와 최종 시험의 상세 결과는 위 구현 결과가 소유한다.
