기존 답변의 시간·공간·플레이어·대상 조건을 먼저 모으고, 같은 선택/WI를 설명하는 질문을 한 흐름으로 연결한다. 각 결과가 어떤 조건을 바꾸어 다음 선택을 가능하게 하는지 원문 근거를 붙인다. 실패·거부·중단·귀환은 해당 기존 규칙이 있을 때 연결하고, 근거가 없는 부분은 `미검토 / 미정 / 제안 / 근거 충돌`로 구분한다. 질문 번호가 빠르다는 이유로 플레이의 선행 단계로 놓지 않는다.

첫 대응은 위 인과 기록 01과 연결되는 자유 이동·정보 판독·후속 선택 근거부터 한다. 이후 농장·약초·방문자·방위·거래/상환 등 기존 분야도 같은 방식으로 검토하되 이 모두가 이 기록 다음에 반드시 실행되는 것은 아니다. 이미 확정된 내용을 처음부터 다시 질문하거나 기존 분야별 승인 원문을 통째로 새 문장으로 덮어쓰지 않는다.

사용자에게 보여 줄 것은 원문을 복사한 긴 목록이 아니라 **상황과 선택의 짧은 흐름 + 이를 뒷받침하는 Q/의미 ID·WI/H·문서 위치 + 실제 미결정 부분**이다. [기존 전체 순환 조회](../../../../AI/generated/planning-inquiry-circulation.md)와 [문답·공간 조회 방식](../../../../../eng/planning-inquiries/README.md)을 재사용하고 원문 검토 수·미검토 수와 실제 구현 성숙도를 별도로 보고한다. 이번 한 사례 기록만으로 전체 재정리가 끝났다고 하지 않는다.

## Q-397 첫 농사 주기의 체감 시간

- 식별: `Q-첫플레이체감-D3-01 · 전체 Q-397`

- 사용자 답변: 첫 직접 농사 체험의 목표를 10~15분으로 채택한다. 선택형 집중 미니게임 제안은 [명상 문답 Q398](../플레이어내면명상/player-mind-meditation.inquiry.r1.md#q-398-선택형-집중-타이밍과-명상-성장)에서 별도로 소유한다.

- 대가: 성과가 빨리 보이는 대신 장기 농사의 시간감은 약해질 수 있다. 이후 반복/다른 작물/대규모 운영의 시간은 별도다.
