# 스토리 영감과 플레이 진행 분리

> 상태: `SupersededForSequentialStoryStudy / RetainedForRuntimeFreedom`, 2026-09-07. 신규 역경 스토리 공부·저작 순서는 [역경 64괘·효사 순차 학습형 스토리 기획](역경64괘효사순차학습기획.md)이 대체한다. 자유 이야기 씨앗 보존, 실제 플레이 순서와 기획 순서의 분리, 기존 코드·저장 호환 경계는 계속 유효하다.

- 기준 판본: `story-inspiration.r1`, 2026-09-05
- 승인 근거: 사용자 요청 — 괘·효를 따라 스토리를 진행하기보다 영감을 얻어 제작에 반영하고 README·문서·코드에 적용한다.
- 적용: 신규 기획과 기존 기획의 후속 개정. 기존 괘·효 순서 강제 규칙을 대체한다.

## 이야기의 구성 기준

인물의 목적, 현재 상황, 갈등, 선택과 대가, 결과·회복·다음 선택이 이야기 구조를 결정한다. 괘상·괘사·효사는 그 과정에서 상황과 관계를 발견하는 선택적 영감 자료다. 고전 원문, 해석, 게임의 창작·각색은 구별해 기록한다.

한 사건은 여러 괘·효에서 영감을 얻거나 아무 괘에도 대응하지 않을 수 있다. 효를 생략·결합·재배열할 수 있으며 이야기 수를 여섯으로 맞추지 않는다. 괘 번호는 제작 순서, 캠페인 수, 해금이나 플레이 순서를 정하지 않는다. 기존 한스 농장·학습 이야기의 구체 선택은 보존하되 원전 위치만을 이유로 다음 사건을 강제하지 않는다.

## 문서와 탐색

주 탐색은 `이야기·인물·사건 → 개별 PLAN → 준비된 주체 → WI·직접 결과 → 필요한 공간·표현 → 구현·검증`이다. 64괘·384효 트리와 기존 `PLAN-STORY-HEX*`는 참고 자료와 안정 링크로 보존한다. 기존 대장의 `Locked`, `Active`, 효 번호, 여섯 자리 검사는 참고 색인의 이력이며 새 이야기의 승인 관문이 아니다. 기존 생성기는 참고 색인 유지 도구로만 사용한다.

기획 추천은 해당 이야기의 목적과 인과로 설명한다. 이전 문서에 남은 육효 강제 진행·괘별 고정 캠페인·전괘 승인 후 다음 괘 개방 규칙보다 이 기준이 우선한다. 개별 사건의 실제 선행 조건과 실패·회복 규칙은 별도 기획이 소유한다.

## 코드의 적용 범위

기존 `Hexagram*`, `Line*`, `HEX-*` API·저장 식별자는 호환 이름으로 유지한다. 캠페인의 `StoryStageCount`는 이야기에서 정한 양의 단계 수이며 괘의 효 수나 WI 개수에서 추론하지 않는다. `CurrentLineOrdinal`은 호환 필드명으로, 실행상 현재 이야기 단계다. 기존 요청·저장에 단계 수가 없으면 종전의 6단계로 읽는다. 신규 이야기에는 단계 수를 명시한다.

캠페인 내 순차 진행은 현재 엔진의 지원 범위다. 이 변경은 임의 분기 그래프, 사건 자동 완료, 새로운 보상·실패 규칙을 만들지 않는다. WI 목록은 캠페인의 임시 권한 목록이며 단계와 일대일 대응하지 않는다. 기존 실패 시 진입 상태 복원·재시도·영구 성과 보존은 유지한다.

## 인계·검증

사용자 요청에 따른 동일 캠페인 규칙의 E1 재검토이며 Logic E3까지만 검증한다. 기존 E7 작업 명세의 판본·해시를 다시 결속하고, 단계 수 1·3·8, 기존 기본 6, 잘못된 단계 수, 조기 완주 거부, Save/Replay·복원과 해시를 확인한다. Unity 실행·화면·서버 연결 증거는 별도다.
