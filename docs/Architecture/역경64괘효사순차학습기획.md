# 역경 64괘·효사 순차 학습형 스토리 기획

- 기준 판본: `hexagram-line-study.r2`, 2026-09-07
- 상태: `AcceptedPlanningBaseline`
- 적용 대상: 역경을 바탕으로 진행하는 신규 스토리 공부·문답·저작
- 기존 기준과의 관계: [스토리 영감과 플레이 진행 분리](스토리영감과플레이진행분리.md)의 자유 분류 우선을 스토리 저작 순서에 한해 대체한다. 기존 인물·사건·안정 ID·코드·저장 호환과 실제 플레이 자유도는 보존한다.

## 목적

지금은 완성된 이야기를 빠르게 분류하는 단계보다 역경을 공부하면서 **아직 비어 있는 이야기**를 하나씩 만들어 가는 단계다. 64괘의 정식 순서와 각 괘의 초효부터 상효까지를 기본 탐색 순서로 사용하되, 이미 충분히 기획했거나 이번 회차에서 명시적으로 건너뛰기로 한 괘·효를 처음부터 다시 쓰지 않는다. 효사를 이야기에 억지로 끼워 맞추지 않고, 원문의 상황·관계·처신·경계가 게임 안에서 무엇으로 바뀔 수 있는지 사용자와 한 질문씩 검토한다.

## 고정하는 공부·저작 순서

```text
제1괘 중천건
  → 괘 전체 의미
  → 초효 → 2효 → 3효 → 4효 → 5효 → 상효
  → 여섯 이야기의 인과와 전체 줄기 검토
제2괘 중지곤
  → 같은 순서
...
제64괘 화수미제
```

- 현재 다루는 괘 안에서는 한 효를 확정하거나 명시적으로 보류하기 전에는 다음 효를 정식 저작 대상으로 삼지 않는다.
- 이전 효에서 남긴 인물 상태·관계·장소·대가·결과를 다음 효가 이어받는지 매번 확인한다.
- 시작 전에 기존 기획 문서와 제작 대장을 대조하여 `상세 기획됨 / 일부 기획됨 / 큰 줄기만 있음 / 미기획`을 구분한다. 상세 기획된 범위와 사용자가 건너뛰기로 한 범위는 현재 문답에서 반복하지 않는다.
- 중천건·중지곤은 서막 큰 줄기와 육효 씨앗을 보존하되 이번 정밀화 회차에서는 건너뛴다. 수뢰둔은 육효 상세 기획이 있으므로 반복하지 않고, 산수몽은 기존 육효 문서를 보존한 채 미확정 세부 검토를 뒤로 미룬다.
- 수천수는 캠페인 큰 줄기와 정체성만 있고 육효가 모두 `Unmapped`이므로 현재 첫 정밀화 대상이다.
- 떠오른 자유 이야기는 버리지 않고 `StorySeed`로 보관한다. 정식 커서를 이동시키지 않으며 해당 괘·효 차례가 왔을 때 다시 검토한다.

## 효 하나의 문답 절차

1. 괘 전체의 괘상·핵심 상황과 지금까지 확정한 큰 이야기 줄기를 짧게 되짚는다.
2. 해당 효의 원문과 출처를 제시한다.
3. 원문을 직역에 가까운 평이한 뜻, 상황 속 의미, 경계할 오독으로 나누어 설명한다.
4. 직전 효의 결과를 이어받는 게임 사건 후보 하나를 추천하고, 원문에 없는 창작은 분명히 구별한다.
5. `지금·여기·나·너·이렇게`, 선택·대가·결과·회복·다음 변화로 사건을 검토한다.
6. 사용자에게 핵심 질문 하나만 묻는다.
7. 답변을 같은 효의 기획 판본에 반영하고 `확정 / 미정 / 다음 질문 하나`를 갱신한다.
8. 해당 효의 이야기 의미가 닫히면 다음 효로 이동한다. WI·H·Graph Map·개발 요구는 이야기 뒤에 기록하며 자동 생성하거나 실행하지 않는다.

## 원문과 각색의 경계

- 괘사·효사 원문, 전통적 문맥 요약, Mirror의 게임 각색을 별도 항목으로 기록한다.
- 원문 출처와 위치를 확인하며 현대 번역문을 출처 없이 복제하지 않는다.
- 효사는 기계적인 퀘스트 명령문이 아니다. 같은 의미를 인물의 선택과 결과로 체험하게 만든다.
- 원문의 흉함·손실·폭력성이 장기 플레이를 막는다면 완화할 수 있지만, 무엇을 바꾸었는지와 이유를 남긴다.
- 이미 승인된 사건이 원문과 부분적으로 어긋나면 삭제하지 않고 `Aligned / Partial / ReworkRequired`로 재검토한다.

## 제작 순서와 실제 플레이의 구분

순차 학습은 **기획자가 공부하고 이야기를 쓰는 순서**다. 이것만으로 다음을 자동 확정하지 않는다.

- 384개 퀘스트의 강제 직선 진행
- 괘 하나당 반드시 여섯 개의 독립 WI
- 효 완료에 따른 자동 해금·보상·실패 복귀
- 기존 캠페인 단계 수·Save/API의 일괄 변경
- Graph Map·H·Unity 구현과 Evidence 승격

실제 캠페인이 효 순서를 사용할지는 해당 괘 기획에서 별도로 정한다. 캠페인 사이 자유 생활, 선택형 사건, 이미 구현된 독립 기능은 유지할 수 있다.

## 현재 문답 위치

- 현재 정밀화 괘: 제5괘 수천수
- 현재 효: 초구부터 시작하되, 먼저 기존 캠페인 큰 줄기가 괘 전체 의미와 맞는지 짧게 확인한다.
- 다음 문답: `初九 需于郊，利用恒，无咎`의 원문 의미를 확인하고, 조사대 출발을 기다리는 동안 플레이어가 농장·훈련장·비축 가운데 무엇을 꾸준히 다지는지 정한다.
- 보존·건너뜀: 중천건·중지곤은 서막 씨앗, 수뢰둔은 상세 승인 기획, 산수몽은 기존 육효 문서를 유지한다. 이는 삭제나 완료 소급이 아니라 현재 문답 우선순위의 조정이다.
