# 플레이어 NPC 학습 중점 E3 구현 결과

## 결론

한 절기의 `초반 → 중반 → 후반` 세 구간에서 비울 수 있는 주 학습 중점 슬롯 한 칸을 운용하는 첫 E3 slice를 구현했다. 한스의 목 `농사일` 카드와 금 `벌목·전투 도끼술` 카드는 결속된 플레이어 행위 기록에만 해당 세부 숙련 이해도 `+1`을 멱등 적용한다.

Logic E3, 읽기 전용 상태 투영을 포함한 Presentation E3, 통합 E3까지만 성립한다. 실제 카드 UI·Unity 입력·Game View·관계 기반 카드 취득·플레이어 멘토 공유·보조 슬롯은 구현하지 않았다.

- 변경: 최초 초반 시작 경계에서는 즉시 적용하고, 절기 중 장착·교체·해제는 다음 구간부터 적용한다. 후반에는 다음 구간 예약을 거부한다.
- 카드: `learning-card:npc:hans:farming.r1`, `learning-card:npc:hans:axe.r1`.
- 대상 WI: Farm `WI-FARM-01~06`, Nature `WI-NATURE-06`, `WI-NATURE-11`.
- 기여: 플레이어 주도 `성공`, `의미 있는 실패`, `후퇴 복구`만 해당 세부 숙련 이해도 `+1`.
- 제외: 취소, NPC 수행, 다른 플레이어, 무관한 WI, 같은 행위 재처리.
- 불변: 생산량·작업 속도·전투 피해·회복·위협·이데아 발견 확률을 직접 바꾸지 않는다.

- 카드 슬롯·보유 카드·구간 예고의 실제 UI와 입력 계약은 E4에서 동결해야 한다.
