# 면목동 전체 수집자료 분포로 관찰 범위 확장

- 사용자 요청: 기존 1km만이 아니라 면목동 전체에 축적된 DB 정보를 최대한 표현한다.
- DB의 면목동 선택 상가5411건을 전부 위치 표식으로 표시한다. 이전 단일 주소801관측/204건물 패널과 사가정602건물/2397도로선분은 그대로 유지한다. 위치표식은 새 실제 건물이나 업무 주체가 아니다.
- 실제 DB `business-verify`: 상가5411+제조126 =5537행 일치, 읽기만 수행했다. 위치 생성은 동일 동결 DB 재조회 사본 `address-review.json` SHA256 `A48B62059B2FE2B6B5D5165949C1C40ECFAD25292154B59BD64FD20EC6A3F41D`에서 이루어진다.
- 원문 좌표 범위: 경도127.072204453973~127.101107343911, 위도37.570920164536~37.593909526486. 이것은 수집 상가 분포이지 면목동 행정경계나 모든 주민/건물 전수범위가 아니다.
- [공식 상가 자료](https://www.data.go.kr/data/15083033/fileData.do)의 위도·경도 제공과 이용허락범위 제한 없음 확인. 원문 측지 기준은 여전히 명시 확인되지 않았으므로 기존 `CRSNotExplicitlyConfirmed`를 유지하고 **WGS84 가정의 검토용 위치**라고 화면에 표시한다. 정확 측량/배달 위치/출입구로 사용하지 않는다.
- 기존 `Get-NeighborhoodMarketPoints`를 재사용한다. 기본500m 제한은 유지하며 명시 인자에서만 최대3000m까지 허용한다. 기존 원점/1unit=1m/동서남북 방향을 유지하고 1km로 축소하지 않는다. `build-myeonmok-wide.ps1`은 같은 입력의 재실행 결과를 대조하고 다른 내용의 기존 출력을 덮지 않는다.
- 비공개 `wide-reference.json` SHA256 `E2420E86BDBCD323E7E52BA7431CF941091C44E0F2D74701C747B810F5FDF928`. Unity Editor에서만 읽고 배포 Resources에 넣지 않는다. ID·이름·주소·업종·층 원문·출처·기준일을 보존한다.
- `면목동전체자료View`는 기존 Root 아래 업종별 결합 Mesh로 5411개 작은 기호를 그린다. 음식 빨강/소매 노랑/기타 파랑. 위치가 겹치는 관측을 임의로 벌리거나 높이로 층을 재현하지 않는다. 기호의 폭/높이는 실제 건물 치수가 아니다. 기존 1km 바깥 도로·건물 외곽·DEM은 아직 추가하지 않았다.
- 좌상단 전체보기 버튼과 이름/주소 검색(최대20결과)을 추가했다. 기존 카메라의 맞춤 범위를 확장하므로 새 Scene·Camera·MapManager를 만들지 않는다. 기존 자료 패널과 별개 검색이며 현재 운영을 확정하지 않는다.
- 제조·의료 등 좌표 미확보/다른 좌표계 자료를 위경도로 오해해 배치하지 않았다. 전지역 실제 건물 외곽 지도를 완성한 것이 아니라 DB 위치 자료를 전범위로 펼친 단계다.
- 검증: 기존 좌표13+맵 오류8종 통과, 생성5411개의 고유ID/원문hash 검증 및 재실행 동일hash. 실제 첫 Play에서 Bounds 값 형식의 복사본 수정 때문에 카메라 범위가 남는 문제를 발견해 지역변수 누적 후 할당으로 수정했다. 최종 화면 결과는 CURRENT_WORK에 기록한다. Scene저장·DB쓰기·commit·push 없음.
- 실제 화면의 기본 Unlit 재질 색상 불일치를 발견하여 기존 `관찰도형명암` 셰이더를 재사용했다. 표식 아래 좌표 참고판을 추가했으며 이를 실제 지형/토지이용/행정경계로 해석하지 않는다. 전체 분포의 조회 범위는 약2553×2552m이다.

## 후속 조화 조정

사용자 요청으로 위 큰 참고판을 제거했다. 기존 주소 연결 소비자가 검증한 고유ID585개를 위치 점에서 제외하되 전체 데이터5411개와 검색은 보존한다. 원거리(카메라 orthographicSize>350)는 나머지4826개를100m 셀355개로 요약하고 근거리는 작은 저채도 표식을 표시한다. 셀의 위치/크기/색은 관측 밀집도 기호이며 토지나 건물이 아니다. 기본 전체보기off에서는 둘 다 숨긴다. 기존 카메라 기본시점과 Scene은 유지한다.

실제 Play 검증스크립트에서 기본숨김·근거리detail만 활성·원거리density만 활성과5411/585/355개수를 확인했다. 밀집도는 기존 바닥 아래(-0.1)에 두어 기존 도로/건물을 덮지 않는다. 기능별 새 Scene·Collider·업무 결과는 없다. 화면 `Documentation/Changes/2026-09-08-myeonmok-data/harmony-ui.png`. 실제 마우스 줌/클릭, 성능 계측, 배달 완주는 별도 미검증이다.
