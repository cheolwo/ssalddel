## 수집·저장 계보

- 출처 등록은 기존 [동네공간SourceRegistration](../../Ssalddel/Services/External/PublicData/Korea/동네공간SourceRegistration.cs)에 시설3종만 추가했다. 기존5종과 ID·사용조건 불변, 자동수집·게시 비활성 유지.
- [기존 ASP.NET 참조 수집 도구](../../eng/Ssalddel.PublicDataPortalImport/README.md)에 `spatial-*` 모드를 추가하고 기존 원본 등록 서비스/EF 저장소를 재사용했다. 새 공공데이터 API/가격/건물 마스터를 만들지 않았다.
- 지역 필터를 넣어도 표준 다운로드가 전국 페이지를 반환하는 것을 직접 확인했다. 공개 페이지8회로 공원18,202/주차장18,878/화장실33,820행(합70,900)을 읽되 DB는 중랑구134행만 저장했다. 전국 원문은 감사용 비공개 파일이다. 수집은 정기/무제한 작업이 아니다.
- 각 데이터의 schema.org/DCAT/열·개수 전후와8페이지를 합친20파일, 58,729,584bytes를 보존했다. 초기/종료 페이지 개수·열 일치 및 행 수를 검사했다. 공급처가 같은 총수 안에서 내용을 교체하는 경우까지 보장되는 일관된 서버 스냅샷은 아니다.
- 공식 DCAT3개에서 `이용허락범위 제한 없음`을 관측했다. 이는 현실 시설의 영업/공간 접근 권한이나 게임 적용 승인이 아니다. 원천 인용·기준일/처리 이력은 계속 표시한다.
- 원본은 `artifacts/local/public-data/jungnang-spatial-20260908-r2/`. 영수증 `acquisition.json` SHA256 `F058734A90B9202B08ED0A68D9288FC324122965E60A5B38E3AF921D7474DD84`를 코드에서 동결하고 각 파일 hash/길이를 다시 검사한다. 자동 기대값 갱신 없음.
- DB `public_data_raw_snapshots` 신규17(공원58행)/18(주차장25행)/19(화장실51행). 중랑구 행이 있는 원본 페이지3개를 계보로 연결한다. 다른 지역만 있는 페이지와 메타데이터는 수집 영수증에 남아 있으며 DB에 전국 시설을 넣지 않았다. 기존시장 원본12/정규화12행은 읽기만 했다.
- `public_data_normalized_records`에는 기관+원천ID 또는 이름/주소 기반 파생ID, 날짜, 종류, 좌표 또는 null, 원문행의 정렬 JSON hash, 기준일/출처 판본을 저장했다. 나머지 원문 속성은 원본 페이지에서 행 hash로 추적한다. 좌표 미확보를 0, 건물 중심, 임의 주소 지오코딩으로 채우지 않는다.
- 같은 기관/식별자/날짜에 다른 내용이 있으면 덮어쓰기 거부. 기존 다른 품질 판정도 덮지 않는다. 전체134행 `PendingHumanReview`, NumericValue null, 비공개 참고자료다.
