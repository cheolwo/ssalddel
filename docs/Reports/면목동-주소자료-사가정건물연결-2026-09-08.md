## Unity 연결 방식

기존 `가상배달관찰Controller.사가정참고조립()`에서 선택적 `면목동주소연결View`를 연결했다. 기존 사가정 지도·카메라·관찰 Root를 그대로 사용한다. 새 Camera/Scene/Renderer/Collider/시설 객체·NPC·주문 상태를 만들지 않는다.

- 동결된 비공개 `connection.json`을 **Unity Editor에서만** 읽는다. 새 Resources나 배포 자료에 원장을 복사하지 않았다. 원본 DB에 직접 연결하거나 Update/Tick에서 수집하지 않는다.
- 다음 해당 프로필 Play에서 우측 `면목동 수집자료 · 건물 참고 121곳` 버튼으로 패널을 열도록 코드 연결했다. 주소/이름 검색, 지도상의 숫자 선택, 주소별 이름·종류·원주소·원천 상태·기준일·출처를 표시한다. 실제 버튼 클릭/화면 판독은 이번 미실행이다.
- 지도 숫자의 위치는 **기존 건물 경계상자의 기호 기준점**이다. 오목 다각형의 내부점, 실제 출입구·접지·높이로 인증하지 않는다. 지리 좌표계를 다시 변환하거나 지도 범위를 넓히지 않았다.
- 연결된 의료63행 중 원천정상43, 폐업18, 제외/삭제/전출2다. 기본 표시는 뒤20행을 제외하고 `이력 포함`으로 확인하게 했다. 다른 자료까지 합친 기본 표시 가능 기록은193행이며 실제 현재 영업 확인이 아니다. 음식점 상태 공란은 `운영상태 미확인`으로 표시한다.
- 파일 없음/변조/지도 판본 변경은 주소 패널만 보류한다. 기존 지도·표현·업무 상태를 가짜 값으로 바꾸거나 없애지 않는다. 새 배포용 실시간 서버 조회는 아직 미연결이다.
