# 법정동 의미 레이어·배치 전 관계 기반 r2

기준 기획: [법정동별 공간 패키지와 공통 오행 업무 객체 r2](../AI/Planning/시스템/PLAN-SYSTEM-NEIGHBORHOOD-SPATIAL-PACKAGES/README.md)

## 결과

- 기존 JSON 구조의 `layer`를 바꾸지 않고 교차 자료 의미를 나타내는 `semanticLayerStableId`를 추가했다.
- 행정·법정동 경계, 좌표계, 건물 윤곽, 도로 중심선, 비공개 주소 연결, 시설·사업체 관측, 인구·경제 통계, 시나리오 오버레이 8개를 공통 의미 레이어로 고정했다.
- 면목동은 기존 Graph Map·배치 Map·건물 602개·도로 2,397개를 유지하고 7개 의미 레이어 결속과 `area:reference:myeonmok → region:kr:bjd:1126010100` 호환 별칭을 추가했다.
- 중화동은 5개 의미 레이어 결속을 추가했지만 공식 경계·건물·도로 geometry가 없으므로 `InventoryReady`를 유지한다.
- 면목동 Unity 인계는 좌표계·건물·도로·시나리오 레이어 참조만 가진 비식별 Manifest다. `ObservationPresentationOnly=true`, `TraversalReady=false`, `GameplayReady=false`, `SceneReady=false`이며 Scene·Prefab을 변경하지 않았다.

## 저장·조회

- `spatial-catalog.r4`가 `SemanticLayerStableId` 선택 필터를 제공한다. 기존 `Layer` 필터와 v1 스키마는 계속 읽을 수 있다.
- 로컬 `hongdal-mongo-1 / ssalddel_dev` 묶음은 `bundle:1862BC54C14DD21CCA5AB38FBCCD9DF1E0674A4331E6B327038C13A12274AAF2`다.
- 구성은 34문서·7,511구성요소·9,692명시 관계이며 의미 레이어 정의 8개와 동별 결속 12개를 포함한다.
- 첫 반입은 신규 17,238건, 같은 입력 재반입은 신규 0건이었다. 독립 재조회와 다른 Mongo 컬렉션 불변을 확인했다.
- 관계 해소 결과는 정확 결속 6,044건, 외부·미해결 2,995건, 복수 표현·판본 653건이다. 해소 결과는 승인이나 배치 권위가 아니다.

## 검증과 상한

- `공간자료CatalogTests`: 24/24 통과.
- 공공데이터 importer build: 경고 0, 오류 0.
- 동별 패키지 전용 검사: 통과.
- 범위 Fast와 Task의 v3.5 전체 build는 통과했다. Task 전체 시험은 4,993개 중 4,986개가 통과했고 이번 범위 밖 기존 Controller metadata 6건과 공식 재료 UI 1건이 실패했다.
- 원본 hash·수량, 의미 레이어 고유성, 면목동 호환 별칭, 개인정보 제외, Mongo 멱등성을 확인했다.
- Unity Editor·Play Mode·Game View·Scene·Prefab, MySQL, 운영 업무 상태, 외부 API 재수집은 실행하거나 변경하지 않았다.

## 남은 관계 결손

- 면목동 공식 법정동 경계와 출입구·층수·통행 가능성은 근거가 없어 배치하지 않는다.
- 중화동은 공식 경계·건물·도로 geometry가 생기기 전 Graph Map·배치 Map으로 승격하지 않는다.
- 다음 법정동은 등록부·동결 원본·의미 레이어 결속을 먼저 만들고, Scene 적용은 별도 검토 뒤 수행한다.
