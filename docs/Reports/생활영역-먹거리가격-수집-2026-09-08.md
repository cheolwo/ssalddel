## 접근·권리·비밀정보

- [공식 API 이용안내](https://www.kamis.or.kr/customer/reference/openapi_list.do)의 인증절차와 기존 서버 .NET User Secrets 설정 존재를 확인했다. 새 로그인·키 발급·활용신청·유료 호출·정기 실행 없음. 포털 로그인 상태를 API 사용권과 동일시하지 않았고 이번은 KAMIS 직접 HTTPS 경로다.
- 첫 요청은 응답의 인증값 되돌림을 감지해 파일 저장 전에 `CredentialEchoRejected`로 차단했다. 이를 숨기지 않고 후속 보완 후2회 요청했다. 실제 HTTP 요청은 총3회이며 자동 재시도는0이다.
- `condition` 전체를 제외하고 `data` 하위 원문만 보존했다. data 내부에도 비밀값이 있으면 저장 거부한다. 저장 파일은 **전체 HTTP 원문이 아닌 안전 추출본**이며 hash도 이 바이트 기준이다. 원래 비밀값/요청 URL은 파일·DB·로그에 저장하지 않았다.
- 공개 API의 정보서비스 활용 안내는 확인했지만 별도 재배포 세부조건은 이번 미확인이다. 사적 검토용 보관과 공개/게임 반입 권리는 분리한다. 비밀값은 최종 산출물·검증 로그에서도 값 없이 포함 여부만 검사한다.
