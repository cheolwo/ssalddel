# 한스 농장·인접 숲 자연경관 조립

## 승인된 구현 범위

사용자는 첫 완성 구역을 **농장과 인접 숲**, 경관을 **숲 가장자리 개간지**로 선택하고 구현을 승인했다. 이 문서는 승인 작업의 범위와 실행 결과를 기록하며, 기존 기획 정본·Graph Map·배치 맵을 대체하지 않는다.

기준: [수뢰둔 정본](../AI/Planning/스토리/PLAN-STORY-HEX03-CAMPAIGN-001/README.md), [숲 경계 농장 배치 기획](../AI/숲경계농장-H1-H2-배치맵-기획-2026-09-02.md), [이전 최소 씬 정리](한스농장-월드화면정리-2026-09-05.md).

## 구현 계약

- 핵심 구획은 의도적으로 설계하고 주변 식생은 결정적 군집으로 배치한다. 집→작업마당→밭/출입구→굽은 숲길의 관계와 집으로 돌아오는 통행 공간을 기존 Graph Map에 결속한다.
- 기존 배치 맵과 AreaSet 저작 도구를 재사용한다. 지형 측정→영역/경계→길→H1 배치→소품/식생 순으로 구현하며 별도 배치 시스템을 만들지 않는다.
- 울타리는 경계선에 연결하고 수리 대상 세 구간은 연속 경계 일부로 유지한다. 외형만 권위 좌표와 다르게 옮기지 않는다.
- 실제 Blender 손상 주택 파생 FBX를 가져와 단위·피벗·재질·Collider를 검증한다. 임시 타운집 축소율을 최종으로 사용하지 않는다. 경작 구획은 기존 2.5×2.5m 모듈을 유지한다.
- 숲 내부는 밀집, 농장 가장자리는 성긴 식생으로 전이한다. 통행과 작업 공간을 가리는 식생을 배제한다.
- Blender와 Unity는 같은 배치 초안을 사용한다. Blender 조감/눈높이 및 Unity 실제 조감/근접 이미지를 제공한다. 지형 자동 평탄화·PNG 후처리·권위 시간 조작으로 문제를 숨기지 않는다.
- canonical Scene의 이전 상태를 백업한다. 마을/물류거점/전체월드/새전투/애니메이션/다른영역 변경/커밋/푸시는 제외한다.

## 판정과 담당

공간 담당이 Graph Map·배치 맵·Blender·Unity 조립과 집중 검증을 소유한다. 본 스레드는 승인 범위·검증 반환·이미지를 통합한다. H2/H3는 사용자 시각 검토 전 후보이며 E 승격은 별도다.

현재 상태: **구현 착수 요청. 아래 검증은 아직 완료가 아니다.**

## 완료에 필요한 검증

1. 같은 배치 입력의 결정성, 재조립·씬 재개방·Play 재진입 시 중복 없음.
2. 집·밭·울타리의 지지면·크기·겹침, 출입·작업·귀환 통로와 Collider 검사.
3. 기존 도끼 회수·벌목·목재·울타리 수리 상태와 실제 대상의 일치. 배치와 권위 변경이 필요하면 동일 입력 판본으로 재결속.
4. 실제 Blender 파생형과 Unity 자산의 연결 및 출력 이미지 직접 검토.
5. 코드·시험·Blender·Scene·실제 Play·실제 입력 증거를 분리해 보고. 구현이 일부만 끝나면 미완료와 차단을 그대로 남긴다.
