## 기획 판정

### UpdateExisting — 8개

- 메인 스토리, 요동성 방어, Hub 발견, 1인칭 집중, 절기·계절, 현행 Graph Map 재검토, 분리 기획 통합, 레이어 우선 작업 흐름.
- 기존 안정 노드·간선·제약·오버레이를 갱신하며 같은 의미의 병렬 요소를 만들지 않는다.

### CreateSubgraph — 2개

- 한스 정밀 손도끼 수리·반환은 3개 계획 노드와 3개 연결 간선을 가진 독립 하위 그래프로 분리했다.
- 거점 간 장거리 경로는 레이어 계약만 통합했다. 실제 분절·병렬 경로 하위 그래프는 좌표·수치·Goal/WI·E7 명세가 없어 `BlockedPendingRouteFixture`로 남겼다.

### CreateGraphMap — 0개

### Blocked — 2개

- 북부 생활권 첫 Graph Map 상세제안 r4는 현행 r10보다 오래되어 역사 참고로만 유지한다.

### NoImpact — 9개

- 명상·표현·자료 후보는 관련 참조만 유지하고 실제 배치나 권위 관계로 승격하지 않았다.

## 레이어·경로 계약

- 기준 공간은 안정 노드·간선·방향·기준점만 소유한다. 다른 레이어는 이를 복제하거나 변경할 수 없다.
- 경로 상태는 `Open`, `Degraded`, `Blocked`, `Unknown`으로 분리했다.
- 비용은 거리·시간·금전·자원·위험 차원과 `contributionKey`·합성 정책을 함께 기록한다. 같은 원인을 여러 레이어에서 중복 합산하지 않는다.
- 용량은 통행 가능 여부와 별도 값이다. 화물 부족이나 처리 지연을 곧바로 도로 차단으로 바꾸지 않는다.
- 모든 경로 효과는 근거 파일·revision·hash·관측 시각·유효 시각·신선도 상태를 가진다.
- 장거리 경로의 현재 비용·용량은 관측값이 없어 `Unknown/null`이다. 임의 수치를 만들지 않았다.
- 플레이어 선택 레이어는 빠름·안전·저렴·대량·균형 후보와 근거를 보여 줄 뿐 자동 Confirm이나 권위 변경을 하지 않는다.
