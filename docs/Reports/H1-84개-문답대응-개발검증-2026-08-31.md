# H1 84개와 문답 대응 — 개발 파일 검증

기준일: 2026-08-31. 상태: **자료 검증·기획 인계 / 신규 H1 선택·등록 미승인**.

## 1. 결론과 책임

84개는 구현된 장소나 Prefab 84개가 아니라 **기능·상호작용 정의52 + 표현 카드32**다. 정의의 승인 참조도 실제 배치·권위 상태·E5 성공을 뜻하지 않는다. 기존 밭, 작업마당, 보관, 거점, 탐색 역할을 먼저 재사용한다.

- 채수 접근은 정의 대장에 명시적 계약 공백이 있다. 그러나 Q143에 이미 **수동급수점 H1** 구상이 있으므로 전혀 새로운 아이디어로 제안하지 않는다. 기존 구상을 Nature 채수 문맥과 대조하여 역할 보완/별도 기능 후보 중 선택할 문제다.
- 방위 장비 준비는 Q228·Q385의 실제 무기고 접근·장착 요구를 기존 농기구 보관 능력만으로 충족했다고 볼 수 없다. 별도 기능 후보 검토가 타당하나 같은 공간의 판본형 역할 확장 가능성도 열어 둔다. **장비 반납 의무·절차는 아직 미정**이다.
- 달이기·물/차 데우기·재가열은 기존 shelter의 제작·보관·출입 역할 보완 우선이다. 매 작업/UI/신용/보험마다 물리 H1을 추가하지 않는다.
- 개발은 자료와 기술 공백을 검증하고 기획이 후보 선택·승인을 맡는다. 이번 보고는 H/WI·원문·대장·E 변경이나 구현 승인이 아니다.

이후 추가된 시각 조사 요청은 [84개 시각 목록](H1-84개-시각목록-2026-08-31.md)으로 분리한다. 본 보고의 파일 검증을 Editor/캡처 증거로 확대하지 않는다. 기존 야간·r129·다른 기능 중지는 유지한다.

## 5. 기획에 돌릴 최소 후보 — 신규 등록 아님

### A. 채수 가능한 수원 접근 역할

**기존 것으로 전부 해결되지 않는 이유:** production/washing은 WaterAccessible을 선언하지만 채수 원천의 상태, 용기 작업 위치와 전송·접근은 명시하지 않는다. exploration-buffer의 HarvestResourceWorkArea는 ResourceNode/Actor/Tool 수준이며 액체 채수·보관 계약이 아니다. 표현 카드 '개울 회랑'은 supportsInteractionH1Refs도 비어 있다.
