## 목적

NPC와 진영의 장기 행동을 Unity 프레임마다 동적으로 계산하지 않고, 플레이어의 현장 활동은 부드럽게 유지하면서 큰 세계 반응을 결정적인 시간 경계에서 묶어 처리한다. 한국 24절기는 전략 턴의 문맥과 마감 단위를 제공하며, 타로 카드는 다음 절기의 운영 화두와 대응 선택을 연다.

## 세 시간층

### 실시간 현장 플레이

- 이동, 카메라, 대화, 탐색, 채집, 짧은 작업과 직접 전투
- Unity 표현 시간과 기존 권위 실시간 시계·BattleTick 경계를 유지
- NPC 장기 전략·전체 물류·상대 진영 계획을 매 프레임 다시 계산하지 않음

### 일 단위 WorldTick

- 기존 `OneTickOneDay` 호환 경계를 유지
- 확정된 NPC 업무, 생산, 운송, 도로 공사, 위임 작업의 진행과 일 단위 결과를 결정적으로 누적
- NPC가 프레임마다 자유롭게 새 목표를 만들지 않고 승인된 작업 계획·역할·역량·자원·기한을 소비

### 절기 마감 전략 턴

- 한 절기 동안 누적된 일 단위 결과와 미완료 업무를 같은 상태 판본에서 읽음
- 상대·적대 진영 활동, 지역 위협, 시장·물류 수요, 작물·기상 국면, NPC 장기 변화와 다음 절기 계획 후보를 일괄 정산
- 절기 이름만으로 생산·가격·사건·몬스터·승패를 자동 확정하지 않음
- 정확 절기 길이와 현실 날짜 동기화는 별도 판본에서 결정

## Solo 절기 마감

Solo에서는 절기 마지막 경계에 정산 미리보기를 보여 주고 플레이어가 명시적으로 `절기 마감`을 확정한 뒤 다음 절기로 넘어간다. 미리보기에는 최소한 다음을 구분한다.

- 완료·진행·중단된 운송·공사·위임 업무
- 아직 해결되지 않은 화물·도로·위협·NPC 상태
- 다음 절기에 이어질 계획과 예상 변화
- 절기 마감 시 확정되는 상대 진영·경제·생태·공동체 계산 범위
- 차단·불확실·자료 신선도 부족

미리보기만으로 WorldTick·WorldRevision·재고·사건 결과를 변경하지 않는다. Hosted의 자동 마감·접속자 합의·현실 시각 정책은 이번 판본에서 정하지 않는다.

## 절기 마감과 새 절기 시작 흐름

```text
이전 절기 정산 미리보기
  → 명시적 이전 절기 마감
  → 새 절기 시작 지점 진입
  → 동결된 덱·규칙 판본에서 결정론적 아르카나 카드 3장 제시
  → 각 카드의 정방향 효과와 역방향 효과를 함께 판독
  → 아르카나 카드 1장 선택
  → 선택하지 않은 2장은 버림 더미
  → 선택 아르카나에 허용된 세계 대응 방식 선택
  → 관계가 열린 한스 등 NPC의 학습 중점 카드 제시
  → 이번 절기에 배울 계열 하나 선택
  → 세계 대응 후보와 개인 학습 중점 효과를 각자 활성화
  → 기존 하위 업무 규칙의 Preview·Confirm·불변 검증
  → 새 절기 현장 활동 시작
```

새 절기가 시작될 때 세 장 중 한 장을 선택한다. 선택하지 않은 카드는 이번 덱 순환의 버림 더미로 보내고 덱을 모두 사용한 뒤에만 동결된 규칙으로 다시 섞는다. Save/Replay는 덱 판본·순서·제안·선택·버림 더미·재섞기 입력을 보존해 다시 불러오기로 유리한 카드가 나올 때까지 반복하는 일을 막는다.

카드 후보에는 정방향·역방향의 기회와 부담을 함께 보여 준다. 세계 문맥형 절기 카드는 기존 `RecoveryShare51` 정책을 재사용한다. 활성화 시점의 권위 회복·위협 상태에서 `회복 출력 ÷ (회복 출력 + 위협 출력)`을 백만분율 고정 정밀도로 계산해 `510000` 이상은 정방향, `509999` 이하는 역방향으로 판정한다. 분모가 0이거나 근거 hash가 없으면 활성화를 거부한다.

Preview는 현재 상태에 따른 방향 후보와 양쪽 효과 설명을 보여 주고, Confirm은 선택 카드의 방향·회복 비중·근거 revision/hash·정책 revision을 새 활성화 사본에 동결한다. 활성 수명 동안 회복 수치가 달라졌다는 이유만으로 방향을 매 Tick 다시 계산하지 않는다. 다만 판본화된 효사·캠페인의 중요 집중 관문에서 성공한 실제 행동으로 회복 비중이 `RecoveryShare51` 기준선을 넘으면, 사용자가 확인하여 같은 카드의 방향을 다시 활성화할 수 있다. 이때 기존 역방향 활성화를 제자리에서 고치지 않고 종료한 뒤 같은 카드의 정방향 활성화를 새 안정 ID와 상속 계보로 만든다. 이미 정산된 결과는 소급 변경하지 않는다. 교체·해제·다음 절기 재활성화도 같은 이력 보존 원칙을 따른다. 기존 seed 기반 세션은 호환을 위해 `SeededHash` 정책을 보존하며, 절기 프로필 결속 없이 전역 정책을 조용히 바꾸지 않는다. 정방향을 순수 보상, 역방향을 순수 벌칙으로 만들지 않는다.

### 중요한 순간의 집중과 같은 카드 재방향

- 재방향 후보는 단순 화면 입력 성공이 아니라 결속된 집중 행동 기록, 회복 변화, 현재 카드 활성화와 같은 사건 revision을 요구한다.
- 기준선을 넘지 못하면 집중 자체의 회복·알아차림 결과만 남고 카드 방향은 유지한다.
- 기준선을 넘더라도 사용자가 확인하지 않으면 현재 활성화를 유지한다. `전부 맡기기` 정책에서는 이안의 자율 판단 Profile이 확인을 대행할 수 있으나 그 근거를 기록한다.
- 역방향에서 정방향으로의 전환은 불리한 운명을 지우는 보상이 아니라, 같은 절기 화두에 대응하는 태도가 달라졌음을 나타낸다.
- 정방향이 된 뒤 회복이 다시 낮아졌다는 이유만으로 자동 역전시키지 않는다. 후속 재방향을 허용하려면 별도의 중요 관문과 Profile이 필요하다.

## 카드의 책임

카드는 다음 절기의 운영 질문과 대응을 연다.

- 전차: 빠른 운송, 안전 운송, 합배송
- 정의: 검수 강화, 공정 배분, 분쟁 재검토
- 여제: 생산 확대, 품질 관리, 노동 부담 완화
- 절제: 재고 균형, 자원 절약, 병목 완화

이는 의미 예시이며 최종 덱·수치·효과가 아니다. 카드는 재고·화물·사고·NPC 성장·전투 결과를 직접 만들지 않는다. 선택한 대응은 기존 생산·운송·창고·시장·도로·전투·NPC 업무 규칙이 받을 수 있다고 선언한 연결 지점에만 판본화된 보정 후보를 제공한다. 기존 권한·용량·수량 보존·음수 재고 금지·Preview·Confirm·상태 재조회 경계를 우회할 수 없다.

### 하나의 절기 시작 화면에서 아르카나와 학습 중점을 이어서 고른다

새 절기 시작은 플레이어가 하나의 의식처럼 이해할 수 있는 통합 화면·흐름으로 구성한다. 먼저 아르카나 카드를 뽑아 이번 절기의 세계 운영 화두를 확인하고, 그다음 한스 농장처럼 관계가 형성된 교습 주체에게서 이번 절기에 무엇을 배울지 성장 중점 카드를 선택한다. 한스의 첫 후보는 목의 `농사일`과 금의 `벌목·전투 도끼술`이다.

이 병합은 화면과 플레이 순서를 하나로 묶는다는 뜻이다. 아르카나는 세계 대응 후보·정역방향·덱·버림 더미를 소유하고, 학습 중점 카드는 플레이어의 교습 주체·학습 의향·선택 계열 효과를 소유한다. 두 선택의 식별자·저장 사본·효과 계산을 합치거나 한 카드가 다른 카드의 결과를 대신 만들지 않는다. 비선택 학습 계열도 잠기지 않고 같은 절기 동안 수행·학습할 수 있다.

절기 마감은 지난 결과를 정산하고, 새 절기 시작은 아르카나 세계 대응과 개인 학습 중점을 차례로 활성화한다. 카드 선택 순간 영구 능력치를 직접 지급하거나 농장 구획·전투 승리를 만들지 않으며, 실제 관련 훈련·작업·행위 결과에만 학습 중점 효과를 적용한다.

학습 중점 효과는 관련 경험·숙련 성장과 이데아 발견 가능성을 높인다. 첫 단계는 약하게 시작하고, 같은 계열에서 실제 완료된 학습·행동과 확인된 이데아 관계가 쌓일수록 단계적으로 강해진다. 선택 횟수·화면 열람·시간 경과만으로 강화하지 않으며 생산량·벌목 속도·전투 피해 같은 직접 결과에는 적용하지 않는다. 정확 단계 수·효과량·상한과 계열 전환 시 보존은 후속 기획으로 남긴다.

### 절기 상태창과 학습 카드 슬롯

상태창의 가장 위에는 현재 24절기의 이름과 게임 날짜 범위, 남은 기간, 다음 절기를 표시한다. 이 헤더는 현재 오행 활동 분포와 절기 카드 효과를 어느 시간 범위로 읽는지 알려 주는 공통 기준이다. 운영체제 시각과 현실 날짜를 임의로 혼합하지 않는다.

헤더 아래에는 다음을 서로 구분해 배치한다.

- `현재 아르카나` 슬롯: 이번 절기의 세계 화두·정/역방향·주요 기회와 부담을 읽는 카드다.
- `학습 중점` 장착 슬롯: 현재 절기에 활성화된 NPC 교습 계열·대표 오행·효과 단계·교습 주체를 보여 주는 큰 카드 슬롯이다.
- `보유 학습 카드` 영역: 관계·교습 조건으로 열린 후보를 스크롤·필터하고, 선택 가능 시점과 잠금 사유를 확인하는 영역이다.
- `오행 활동` 영역: `현재 절기`를 기본으로 보여 주고 `최근 활동`, `전체 이력`으로 전환한다. 원소별 실제 누적값은 독립 보존하고 그래프에서만 선택 기간의 100% 상대 분포를 표시한다.

아르카나는 새 절기 시작에 반드시 하나를 선택하고, 명시적 확인 후 그 절기가 끝날 때까지 해당 활성화 사본을 고정한다. 학습 중점 카드는 반드시 장착해야 하는 절기 카드가 아니다. 플레이어는 선택 가능한 학습 카드가 있어도 장착하지 않고 중립 학습 상태로 남을 수 있다.

학습 카드 장착은 보유 영역에서 장착 슬롯으로 드래그 앤 드롭하거나, 모바일·키보드·접근성을 위해 `카드 선택 → 슬롯 장착 → 확인`으로 수행한다. 드래그 완료만으로 권위 상태를 바꾸지 않고, 효과·교습 주체·다음 정산 WorldTick·교체 제약을 보여 준 뒤 명시적 확인으로 요청한다. 절기 중간에도 새 장착·교체·해제를 요청할 수 있지만, 새 효과는 **다음 WorldTick 정산 구간의 시작 경계**에서부터 적용한다. 이미 진행·완료된 구간은 이전 카드와 규칙 판본으로 정산하며 소급해 바꾸지 않는다.

장착된 학습 카드는 판본화된 `LearningEffectCadenceWorldTicks`마다 효과 적용 구간을 정산한다. 해당 구간에 같은 계열의 실제 학습·교습·작업·훈련 `ActionRecord`가 있을 때만 관련 경험·숙련·이데아 발견 보정 후보를 적용한다. 카드를 장착한 채 대기한 것만으로 영구 경험·숙련·이데아를 생성하지 않는다. 같은 WorldTick 구간·카드 활성화·ActionRecord는 멱등하게 한 번만 정산하며 Save/Replay로 정산 시점을 반복해 보정을 중복 획득하지 못한다.

### 절기 안의 WorldTick 선택 분기

한 절기를 시작과 마감 사이의 단일 긴 구간으로만 두지 않고, `LearningEffectCadenceWorldTicks`와 결속된 여러 선택 분기로 나눈다. 각 분기에서 플레이어는 최근 구간의 실제 행위, 오행 활동 분포, 적용된 학습 카드 효과와 다음 구간 예고를 보고 장착 유지·교체·해제를 선택할 수 있다.

- 분기점은 선택 기회이며 학습 카드를 강제하거나 새 퀘스트를 자동 생성하지 않는다.
- 상태창·작은 알림으로 분기 도달을 알리되, 카드 화면을 강제로 열거나 현장 이동·전투·작업을 즉시 중단하지 않는다.
- 플레이어가 분기를 열지 않으면 현재 카드 또는 빈 슬롯을 다음 구간에도 유지한다.
- WorldTick 분기는 Unity 프레임 시간이 아니라 권위 일 단위 상태·정산 계보에 귀속한다.
- 한 절기의 학습 정산은 `초반 → 중반 → 후반` 세 구간으로 나눈다. 절기 시작에 첫 카드 상태를 정하고, 초반·중반 종료 분기에서 다음 구간의 유지·교체·해제를 선택할 수 있다. 절기의 정확한 WorldTick 길이가 3으로 나누어지지 않을 때 나머지 Tick을 어느 구간에 배정할지는 시간 Profile이 소유한다.
- 첫 구현은 외부 시간 Profile이 제공한 연속된 초반·중반·후반 세 구간을 그대로 소비한다. 최초 초반 시작 경계에서는 즉시 장착할 수 있고, 절기 중 장착·교체·해제는 다음 구간 시작부터 적용한다. 후반에는 다음 구간이 없으므로 새 변경을 예약하지 않는다.

### 두 내부 전략 분기와 방어·공세

초반·중반·후반의 세 구간은 절기 안에 정확히 두 번의 내부 전략 분기를 만든다. 이 분기는 학습 카드만 바꾸는 메뉴가 아니라, 다음 구간에 병력·치료·보급·시설 수리·정찰·공세를 어디까지 배정할지 다시 정하는 짧은 전략 관문이다. 현장 이동과 전투는 실시간 또는 기존 BattleTick에서 계속 처리하고, 분기 선택과 그 결과의 세계 합류는 권위 WorldTick·WorldRevision에 결속한다.

```text
절기 시작 — 아르카나·첫 학습 중점·초기 배치
  → 초반 WorldTick과 현장 플레이
  → 내부 분기 1 — 정찰·차단·보급·예비대 조정
  → 중반 WorldTick과 방어 또는 제한 공세
  → 내부 분기 2 — 치료·수리·재배치 또는 공세 확대/철수
  → 후반 WorldTick과 결전·귀환
  → 절기 마감 — 손실·회복·영토·다음 위협 정산
```

- 기본 압력은 거점과 주민·생산·보급로를 지키는 디펜스다. 아무 선택도 하지 않았다고 자동 승리하거나 자동 공세가 실행되지는 않는다.
- 플레이어는 상황과 준비가 맞으면 정찰대 차단, 접근로 교란, 적 보급선 공격, 전초 거점 점령 같은 제한 공세를 선택할 수 있다. 이 결과는 적 병력·정보·사기·도착 시각·전리품과 다음 방어 조건을 바꿀 수 있다.
- 상대 성 점령은 한 번의 분기 카드로 즉시 끝나는 행동이 아니다. 발견·정찰·보급로·진입 경로·공성 준비·전투·점령 뒤 방어와 귀환이 필요한 상위 캠페인으로 두며 여러 절기에 걸칠 수 있다.
- 공세 실패는 아군 부상·소모·사기 저하·회복 감소·위협 상승으로 다음 방어를 어렵게 할 수 있다. 성공도 적의 모든 행동을 지우지 않고, 확인된 부대·경로·시설에만 효과를 적용한다.
- 두 분기 모두 `방어 강화 / 제한 공세 / 회복·재정비 / 현 상태 유지`의 유효한 선택을 열 수 있지만, 실제 선택지는 정찰 정보·병력·보급·권한·거리·날씨·남은 시간에 따라 달라진다. 사용할 수 없는 선택은 이유를 보여 주고 가짜 가능성을 만들지 않는다.
- 플레이를 타이트하게 만드는 수단은 강제 팝업이 아니라 다음 위협의 도착 범위, 미완료 준비, 현재 병목과 선택을 바꾸지 않았을 때의 예상 손실을 읽을 수 있게 하는 것이다.

첫 구현 표본에서는 성 점령까지 열지 않는다. Farm 외곽의 방어 준비와 짧은 정찰·차단 공세가 같은 절기의 두 분기와 다음 방어 조건으로 돌아오는 작은 폐루프를 먼저 검토한다.

### NPC 고유 학습 카드 풀

초반 플레이에서는 관계가 열린 교습 주체가 한스뿐이므로 한스의 학습 카드만 보유 목록에 드러날 수 있다. 이후 NPC를 만나 해당 NPC의 고유한 기술·관점·작업 습관을 관찰하고 학습 자격을 얻으면 그 NPC의 학습 카드가 보유 풀에 등록된다.

- 카드 식별은 `교습 NPC + 학습 주제 + 카드 판본`을 보존한다. 같은 NPC가 여러 주제를 가르치거나 같은 주제를 서로 다른 NPC에게서 배울 수 있다.
- 카드 등록은 대화 화면 열람만으로 자동 발생하지 않고, 관계·약속·공동 행동·교습 허락·핵심 관계 관찰 중 해당 Profile이 요구하는 근거를 확인한다.
- 한 번 정당하게 등록된 학습 카드는 해당 NPC와 같은 장소에 있지 않아도 다음 학습 구간에 장착할 수 있다. 이는 NPC가 멀리서 실시간 지도한다는 뜻이 아니라, 이미 배운 관점을 현재 학습 중점으로 삼는다는 뜻이다.
- 카드 선택은 다른 학습 계열을 잠그거나 NPC와의 관계를 소비하지 않는다. 해당 구간에 어느 발전 방향을 먼저 보겠다는 선택이다.
- 현재 학습 슬롯은 비울 수 있는 주 슬롯 한 칸으로 확정한다. 성장 후 보조 슬롯은 이번 규칙과 저장 판본에 넣지 않고 별도 기획·Migration 대상으로 남긴다.

NPC 카드와 별도로, 다른 플레이어가 공개에 동의하고 서버가 검증한 경험 사본은 `플레이어 멘토 카드`로 보유 학습 카드 영역에 들어올 수 있다. 두 종류는 같은 장착·다음 구간 적용 리듬을 사용하지만 출처와 취득 근거를 구분한다. 멘토 카드는 다른 플레이어의 전체 능력치·아이템·이데아·세계 상태를 복사하지 않고, 수신자의 관련 실제 행동이 있을 때만 학습 보정 후보가 된다. 정확 발행·취득·철회·차단 계약은 [플레이어 내면·명상 문답](../Architecture/PlayableLoops/PlanningSessions/플레이어내면명상/player-mind-meditation.inquiry.r1.md)의 별도 E1 후보가 소유한다.

전략 턴 상태창은 장착 슬롯과 보유 카드를 열어 상세 정보, 현재 정산 구간, 다음 정산 WorldTick과 오행 활동 분포를 보여 준다. 아르카나 슬롯은 절기 중 잠근 고정 상태를 유지한다. 학습 슬롯의 절기 중간 변경은 다음 구간부터 적용하며, Save/Replay 재조회·클라이언트 시각 변경·드래그 연출만으로 장착 상태를 바꾸지 않는다.

## NPC·적대 진영 연산 통제

- NPC의 일상 업무는 확정된 작업 계획을 일 단위 WorldTick에서 누적한다.
- 장기 목표 갱신과 적대 진영의 큰 행동은 절기 마감 입력으로 묶는다.
- 현장 전투는 기존 BattleTick으로 처리하고 결과만 World 상태에 합류한다.
- 로컬 LLM 대사는 허용된 상태 사본을 필요할 때 읽는 비권위 표현이며 NPC 전략 계산·카드 선택·턴 결과를 대신하지 않는다.
- 같은 입력·규칙·덱·WorldRevision은 같은 후보와 마감 결과를 만들어야 한다.

## 기존 시스템 리팩터링 인계

개발은 새 턴 원장이나 두 번째 카드 권위를 만들기 전에 다음 기존 경계를 대조한다.

- 턴 상황 조회 → 턴 마감 미리보기 → 명시적 확정 → 상태 사본 재조회
- `ExpectedRevision`, 멱등 Command, Save/Replay hash
- 기존 일 단위 WorldTick과 다음 경영일 활성 효과
- 타로 원형·게임 해석·시나리오 덱·카드 제안·대응·배치 객체 반응 계약
- 현재 활성 카드 한 장과 보정 연결 지점·상한·하한·불변 검증
- Unity 카드 서랍과 턴 마감 UI의 읽기 전용 책임

리팩터링은 `일 단위 효과`와 `절기 범위 효과`를 조용히 같은 값으로 합치지 않는다. 기존 공개 ID·Fixture·저장 판본을 보존하고, 절기 문맥·제안·버림 더미·재섞기·활성 기간을 기존 계약으로 표현할 수 있는지 먼저 조사한다. 계약이 부족하면 정확 호환 경계와 Migration을 제안하고 새 schema를 최소화한다.

## E와 실행 경계

- 이 문서는 승인된 기획 기준선이며 코드·Runtime·Unity 완료 증거가 아니다.
- 개발은 정적 계약·결정성·저장·회귀를 먼저 검증한다.
- 실제 절기 마감 입력, 카드 선택 화면, 다음 절기 결과, Game View는 별도 PlayableLoop·Goal·E7 작업 명세와 실행 증거가 필요하다.
- 외부 LLM·유료 호출·운영 DB·Scene 저장·E 자동 승격·commit·push를 자동 포함하지 않는다.
