# 신티 원형 기반 Blender 모델 고도화 전략

- 기획 ID: `PLAN-VISUAL-SYNTY-REFINEMENT-001`
- 분야: 표현·모델 제작
- 판본: `synty-blender-refinement.r1`
- 상태: `ApprovedDirection / ExecutionDeferred` — 방식 채택, 실행 보류
- 승인 근거: 사용자가 신티를 원형으로 Blender에서 고도화한 뒤 Unity에 배치하는 방식을 프로젝트에 문서화하도록 요청했다. 지금 작업을 시작하라는 승인은 아니다.
- 상위·연결: [E4 후보 풀](../PLAN-PRESENTATION-E4-POOL-001/README.md), [H1 자산·상태 조사](../PLAN-PRESENTATION-H1-SYNTY-STATE-001/README.md)
- 기존 표본: [한스 농장 표현 기획](../PLAN-VISUAL-HANS-FARM-001/README.md). 기존 승인 본문·hash·후보·중단 상태는 변경하지 않는다.
- 관련 WI·플레이 순서: 새 WI나 캠페인 진행을 추가하지 않는다. 향후 선택한 H1과 기존 WI에 표현 후보만 연결한다.
- Graph Map 영향: 주체·관계·제약은 유지한다. 실제 후보가 마련되면 기존 자산 참조·판본과 배치 맵을 결속하며 지금 원본을 수정하지 않는다.
- 인계 상태: 개발 인계·Goal 활성화 없음. 다음 질문은 사용자가 재개할 때만 진행한다.

## 확정한 방향

신티 프리팹을 최종 외형으로 고정하지 않고, 기능과 공간을 빠르게 구성할 수 있는 기본 원형으로 활용한다. 외형 고도화를 대상으로 선정한 모델은 **신티 원형 선택 → Blender 고도화 → 사용자 시각 검토 → Unity 배치·검증** 순서로 준비한다.

폴리곤 수 증가 자체가 목표는 아니다. 목표 화풍에 맞는 윤곽·모서리·두께·접합부·재질·풍화의 완성도를 높인다. 모든 신티 자산에 가공을 강제하거나 기존 Unity 후보를 일괄 교체하지 않는다.

## 향후 적용 절차

1. **원형과 역할 확인:** H1 역할, 원본 프리팹/GUID, 크기·피벗·출입구·상호작용 기준점과 기존 자산을 확인한다.
2. **Blender 형태 고도화:** 플레이 거리에서 보이는 윤곽과 접합부를 우선한다. 주택이라면 처마·지붕 두께·기둥·창틀 등을 후보로 검토한다.
3. **재질 준비:** 목재·금속·지붕 등의 차이를 표현한다. 원본 UV·재질 구성을 확인하고 Unity로 전달할 텍스처·재질 설정을 준비한다. Blender 전용 절차형 재질이나 검토 조명만으로 최종 품질을 판정하지 않는다.
4. **필요 상태 구성:** 정상·손상·수리 등 해당 WI가 요구하는 상태만 준비한다. 같은 물체의 정체성·크기·기준점을 유지하며 진행·중단·회복 표현은 기존 E4 요구를 따른다. 모든 상태마다 별도 mesh를 만드는 것은 강제하지 않는다.
5. **시각 검토:** 개별 근접 이미지와 주변에 놓인 이미지로 형태·접점·상태 구분을 확인한다. 파생 `.blend`와 상태별 PNG를 이해하기 쉬운 이름과 판본으로 보존한다.
6. **Unity 검증:** 별도 실행 승인 후 실제 재질·축척·접지·Renderer/Collider·상호작용 위치·상태 결속을 확인한다. Blender 채택이 Unity 검증을 대신하지 않는다.

## 기존 개발 체계와의 관계

- [Synty 표현 모듈 체계](../../../../Architecture/플레이폐루프Synty표현모듈체계.md)의 기존 조립 우선·원본 보존·권위 분리를 유지한다. 이 기획은 최소 기능 표현과 별도로 **시각 품질 고도화가 승인된 대상**의 제작 순서를 정한다. 기존 최소 E4 후보를 일괄 무효화하지 않는다.
- **Presentation E4:** 고도화 모델·재질과 필요한 상태 표현을 준비하고 후보 판본·출처·검토 결과를 남긴다.
- **Presentation E5:** 승인된 후보를 실제 Unity World와 같은 revision의 논리 상태에 결속하여 판독·배치를 검증한다.
- **Presentation E6:** 실제 애니메이션·동작 전이·중단·귀환을 별도로 다룬다.
- 이미지 확인이나 모델 보유만으로 E를 승격하지 않는다. 서버·Simulation 권위와 H 식별자는 외형 개선으로 바꾸지 않는다.
- 원본 신티와 기존 파생본을 보존하며 고도화본은 별도 판본으로 저장한다. 원본 출처·파생 관계를 유지하고 공급사 자산을 독립 재배포하지 않는다.

## 미정·이번 작업의 제외 범위

첫 표본으로 생활주택 H1의 정상 상태부터 외형 기준을 정한 뒤 손상·수리 상태로 확장하는 안을 **추천 후보**로 남긴다. 첫 대상, 세부 화풍·품질 기준, 폴리곤·텍스처·성능 예산, 일정은 아직 확정하지 않았다.

이번 승인은 문서화에 한정한다. Blender 실행·모델 가공·Unity 변경·자산 구매·작업 스레드 인계·자동 실행·기존 중단 작업 재개는 하지 않는다.
