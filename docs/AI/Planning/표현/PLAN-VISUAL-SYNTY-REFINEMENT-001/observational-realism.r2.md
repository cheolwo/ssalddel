## 변경 이유

Mirror는 사용자가 이안과 세계의 변화를 지켜보다가 중요한 순간에 개입할 수 있는 관찰형 게임을 지향한다. 화면에 오래 머무는 생활 공간과 상태 변화는 단순 배치용 저폴리 원형만으로는 구조·재질·사용 흔적을 충분히 읽기 어려울 수 있다. 따라서 Synty를 버리거나 즉시 교체하지 않고 **형태·규격·피벗·배치의 빠른 원형**으로 사용하며, 선택된 대상만 Blender에서 관찰형 실사 지향 파생형으로 고도화한다.

`실사 지향`은 모든 자산을 고폴리곤이나 사진 복제물로 만드는 뜻이 아니다. 실제 구조와 재료가 납득되고, 가까운 관찰에서도 접합·마모·무게·지면 접촉이 무너지지 않으며, 기존 Mirror 공간과 함께 놓였을 때 양식이 급격히 끊기지 않는 수준을 뜻한다.

## 표현 요구 카드에 남길 모델링 단서

모델러나 후속 Codex가 자산 이름만 보고 추측하지 않도록, 대상별 카드에 다음 단서를 기록한다.

| 단서 | 기록 내용 |
| --- | --- |
| 관찰 거리 | 조감·중거리·근거리 중 어디에서 상태와 재질을 읽어야 하는지, 대표 카메라 방향 |
| 실제 구조 | 부재의 두께와 결합 방식, 하중을 받는 곳, 지면·벽·다른 부품과 만나는 접점 |
| 상태 원인 | 왜 손상·오염·습기·마모가 생겼으며 어느 방향과 위치에 축적되는지 |
| 상태 연속성 | 정상·손상·작업 중·완료가 같은 물체로 보이게 유지할 부분과 달라질 부분 |
| 실루엣 단서 | 멀리서도 상태를 구분시키는 기울기·빠진 부재·처짐·부피 변화 |
| 표면 단서 | Albedo뿐 아니라 Roughness·Normal·AO로 나타낼 목재·금속·흙·천의 차이 |
| 상호작용 단서 | 손·도구·화물·물·문 등이 닿는 `InteractionAnchor`, 접촉점, 비워야 할 작업 영역 |
| 배치 단서 | Pivot, 실제 축척, 지지면, 지형 허용 오차, 통로·시야·Collider와의 관계 |
| 성능 단서 | 관찰 거리별 필요한 세부도, LOD·텍스처 공유·반복 배치 가능성. 정확 예산은 측정 뒤 결정 |
| 비교 산출물 | 같은 조명·카메라의 개별 근접 이미지와 실제 배치 문맥 이미지, 상태별 이름과 판본 |

단서는 “낡게”, “실사처럼” 같은 추상어로 끝내지 않는다. 예를 들어 목재라면 결 방향을 따라 갈라짐이 생기는지, 못·장부·끈 가운데 무엇으로 결속되는지, 지면과 닿는 아래쪽에 습기·흙먼지가 모이는지처럼 모델과 재질에서 확인 가능한 말로 작성한다.

## Blender 고도화 기본 순서

1. 표현 요구 카드의 `ModelIdentity`, 상태 변형, 관찰 거리와 배치 맥락을 확인한다.
2. 기존 Synty 후보의 GUID·축척·Pivot·Bounds·재질 슬롯을 측정해 기준 사본으로 보존한다.
3. 원형의 모듈 크기와 배치 접점을 유지한 채 실제 구조에 필요한 두께·모서리·접합부·고정구를 보강한다.
4. 무작위 노이즈가 아니라 노출·사용·하중 원인에 따른 마모와 손상을 만든다.
5. 상태별 별도 Mesh, 교체 부품, 재질 변형, Unity 조립 중 가장 작은 수단을 선택한다. 모든 상태를 별도 Mesh로 강제하지 않는다.
6. PBR 전달을 전제로 Base Color·Normal·Roughness/Mask·AO와 UV·텍셀 밀도를 검토한다. Blender 조명에 구운 명암으로 결함을 숨기지 않는다.
7. 개별 근접 화면과 배치 문맥 화면을 같은 카메라·조명 조건으로 비교한다.
8. `.blend`·내보내기 후보·상태별 이미지에 원천 GUID, 파생 판본과 대상 H를 기록한다.
9. Unity E5에서 실제 재질·축척·접지·Renderer·Collider·Bounds·InteractionAnchor를 다시 검증한다.

## 양식과 일관성 경계

- Synty 원형의 모듈성·읽기 쉬운 실루엣·기존 H 배치 규격은 가능한 한 유지한다.
- 날카로운 90도 모서리는 실제 마모 폭과 관찰 거리에 맞는 bevel을 검토하되, 폴리곤 수 증가 자체를 품질로 보지 않는다.
- 손상은 모든 면에 동일한 얼룩과 균열을 뿌리지 않는다. 비·햇빛·흙·사람의 손·바퀴·도구가 닿는 위치에 근거한다.
- 수리 완료 상태는 새 물체로 교체된 것처럼 보이기보다 기존 부재와 새 부재의 색·거칠기 차이, 보강 흔적으로 동일 물체의 이력을 남길 수 있다.
- 관찰형 카메라에서 보이지 않는 내부를 과도하게 제작하지 않는다. 문·창·파손 구멍처럼 시야가 열리는 곳만 내부 깊이와 차폐를 검토한다.
- 기존 정교한 양식화 후보와 실사 지향 파생 후보는 함께 보존한다. 사람의 비교 검토 전에는 어느 하나를 일괄 정본으로 승격하지 않는다.
