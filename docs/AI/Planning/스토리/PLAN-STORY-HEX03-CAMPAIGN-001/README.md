## 캠페인 약속

나무꾼의 몸에 빙의한 모험가는 낯선 한스 농장에서 작은 노동과 공동 행동을 쌓아 첫 생활 거점을 만든다. 농장을 소유하거나 한 번에 크게 확장하는 이야기가 아니라, 한스의 허가 안에서 머물고 일하고 지키며 회복 가능한 질서를 세우는 이야기다.

주인공의 개인적인 바람은 거창한 영웅담보다 마음 편히 살아갈 자리와 생계를 마련하는 것이다. 한스 농장에 머물며 약초를 기르고 생활에 쓰거나 판매해 돈을 모으는 경로는 이 바람을 드러내는 대표 자유 생활이다. 다만 약초 재배·가공·판매는 수뢰둔 육효의 필수 완료 조건이 아니며, 허가받은 공간과 실제 생산·거래 규칙이 준비된 범위에서 선택적으로 이어진다.

완주하려면 다음 네 조건이 같은 캠페인 시도 안에서 모두 성립해야 한다.

1. 휴식·식사·소량 보관이 가능한 체류권
2. 공동 행동과 약속 이행으로 형성된 한스의 신뢰
3. 관리 상태로 회복한 감자 경작 구획 H1과 완전히 수리한 생활주택
4. 부분 손실 뒤에도 복구할 수 있는 농장 방어 기반

완주 뒤 지도와 상세 정보에는 `한스 농장 · 공동 생활 거점`을 표시한다. 소유자는 계속 한스이며 플레이어에게는 승인된 생활권과 제한 관리권만 남는다.

## 진행 규칙

- 수뢰둔은 첫 본격 캠페인이므로 한스 농장을 처음 발견하면 초구가 시작된다.
- 현재 기준에서는 `초구 → 육이 → 육삼 → 육사 → 구오 → 상육`을 선형으로 진행한다. 각 효는 자신의 `지금·여기·나·너·이렇게 → 결과`를 모두 닫은 뒤에만 다음 효를 연다.
- 각 효를 완료하면 다음 효의 `진행 가능` 상태가 열린다. 별도 효 선택 카드는 요구하지 않지만, 다음 효 기획이 정한 이야기·세계 상태 관문과 공간 발동 접점을 충족하기 전에는 핵심 사건을 시작하지 않는다.
- 실제 후속 사건은 다음 정상 월드 틱부터 조건이 맞을 때 발생한다. 효마다 고정 월드 틱이나 절기 수를 배정하지 않는다.
- 구오의 밭 관리와 집 수리는 원하는 순서로 하거나 병행할 수 있지만 둘 다 끝나야 구오가 완료된다.
- 각 효의 필수 사건을 방해하지 않는 범위에서 농장 노동·채집·휴식·약초 준비 같은 자유 생활을 병행할 수 있다. 자유 생활을 오래 했다는 이유만으로 다음 효를 자동 완료하지 않는다.
- 수뢰둔 완료 뒤에는 한스가 허용한 별도 소규모 구획에서 약초 재배 생활을 확장할 수 있다. 정확 약초·재배 주기·가공·판매처는 `PLAN-GAMEPLAY-HERBAL-CRAFTING-001`과 후속 경제 기획이 소유한다.
- 육삼에서 숲닭 가축화 선택 활동을 열 수 있으나 육사 이후의 필수 조건, 상육 방어 대상과 캠페인 완주 판정에는 포함하지 않는다.
- 상육에서 어떤 대상이 손상될지는 준비한 방어선·전투 위치·현장 대응으로 결정한다. 첫 수뢰둔 시도에서는 완벽 방어를 허용하지 않고 하나의 회복 가능한 부분 손실을 보장한다.
- 기본 공격·방어는 수뢰둔에서 사용할 수 있다. 산수몽은 같은 조작의 자세·타이밍·연계·상대 판독을 배우는 후속 캠페인이다.
- 부분 파손·작물 피해·자원 손실은 `RecoverableSetback`이며 현재 효와 세계 상태를 유지한다. `HansLost`, `HansFarmFullyLost`만 캠페인 실패로 판정한다.
- 상육 완료 뒤 수뢰둔 결과를 영구 확정하고 자유 생활로 전환한다. 한스의 경비대장 소개는 열리지만 산수몽은 플레이어가 명시적으로 시작한다.

표현이 필요한 효는 같은 행에서 H의 전·중·후 상태와 Blender·배치 단서를 부속 카드로 연결한다. 초구의 손상→수리 울타리 카드가 첫 표본이며, 다른 효의 표현 카드는 해당 효의 다섯 조건이 닫히기 전에 앞서 만들지 않는다. 기존 H·시안·모델·배치 기록은 참조 이력으로 보존한다.

이 표는 성장량을 계산하기 위한 측정 자리만 확정한다. 타격 50회나 몬스터 50마리 같은 수치를 수뢰둔에 바로 강제하지 않으며, 적 수·행동별 경험치·숙련 곡선이 승인된 뒤 `Minimum / Expected / Mastery` 수치를 채운다.

마차 손상·부상·지연처럼 다음 장면에서 읽을 수 있는 상태는 가능한 한 진행 차단이 아니라 장면 변형으로 사용한다. 반대로 효의 의미를 성립시키는 약속 이행, 제한 권한, 직접 작업 결과, 핵심 보호 대상의 생존은 숨은 보정으로 대신하지 않는다. 타운 경비 초소 H1은 새 공간 요구사항 `TownGuardPostEntry`로 기록하되 기존 H 대장과 중복 여부를 조사하기 전에는 안정 ID나 Prefab을 임의 확정하지 않는다.

## 주체·WI·H 인계 원칙

- 개발은 주체를 먼저 확립하고 각 효의 직접 상호작용, 직접 결과, H 결속 순으로 내려간다.

- 공간 의미는 생활주택 H1, 2.5×2.5m 감자 경작 구획 H1, 울타리 방어 병목 H1과 이들을 울타리 안쪽 순환로로 묶는 숲 경계 농장 H2를 재사용 후보로 삼는다. 시각자료는 H1 세 건만 채택 후보이며 H2·H3 구성 이미지는 미정이다.

- Presentation E5는 권위 상태와 실제 World 객체의 최소 판독 표현까지다. 실제 동작·AnimationClip·전이·중단·귀환 검증은 E6에서 다룬다.
- 이 기획은 주체·WI·H·Graph Map을 선언할 뿐 자동 생성하거나 Unity Scene에 배치하거나 Evidence를 승격하지 않는다.

- 육사: `WI-WORLD-BOUNDED-MANAGEMENT-GRANT`와 생활주택·감자 구획 H1이 있다. 별도 H2는 요구하지 않으며 한스의 부여 권한과 이안의 수령 자격을 정밀화해야 한다.
- 구오: `WI-FARM-01`, `WI-WORLD-04`와 두 H1 직접 결과가 있다. 별도 완료 H2를 만들지 않고 작업 단계·재료·시간을 정밀화해야 한다.
- 상육: 방위 소집·결과·귀환·성찰 WI와 생활주택·감자 구획·울타리 H1이 있다. 방어·회복 H2와 캠페인 H3는 승인 전 후보이며 첫 야수 구성과 부분 손실 판정이 남았다.
- 효사 요구 대장은 육삼 r4, 육사·구오·상육 r5를 참조해 실제 문서보다 오래되었다. 대장의 `ReadyForDevelopment`를 최신 인계 완료로 보지 않고 육효의 다섯 조건을 닫은 뒤 revision·hash를 재결속한다.
- 현재 문답 커서는 수뢰둔 육삼의 `지금`이다. 추천 후보는 육이 귀환 다음 날 이른 아침, 밤사이 흔적이 더 흐려지기 전에 한스와 경계 지점으로 돌아가는 것이다.

- 주체 대장: `eng/execution-ledgers/gameplay-subjects.json`
- 효별 요구 대장: `eng/execution-ledgers/hexagram-line-planning-requirements.json`
- 캠페인 Graph Map: `eng/world-seedbeds/graph-maps/hans-farm-hex03-campaign.v1.json`
- 배치 준비 프로필: `eng/world-seedbeds/placement-map-profiles/hans-farm-hex03-development-handoff.v1.json`
- 시각 후보 원본 대장: `eng/execution-ledgers/hex03-h-visual-catalog.json`

과거 `LogicReadyForDevelopment`와 효사 요구 대장의 `ReadyForDevelopment`는 당시 문서 판본에 대한 이력이다. 현재 효 문서가 더 새롭고 다섯 조건 정밀화가 진행 중이므로 최신 인계 완료로 재사용하지 않는다. H2·H3 시각 구성은 품질 재검토 전까지 미정이며 공간 표현 개발 준비도 완료되지 않았다. 새 WI 세 건은 등록만 된 E0이며, Unity 구현이나 Presentation E5가 완료됐다는 뜻이 아니다.

## 검증 시나리오

- 초구의 벌목·목재·수리 기록과 재회 시 한스의 사실 확인이 같은 원인 계보를 가리킨다.
- 육이 순환로는 밭을 울타리 안쪽에 포함하고 시작점으로 귀환할 수 있다.
- 육삼은 깃털·발자국·눌린 식생의 관찰 사실과 배후 추정을 별도로 보존한다.
- 육사 권한으로 생활주택과 지정 밭만 변경할 수 있고 농장 전체 철거·확장·소유권 변경은 거부한다.
- 구오의 두 작업은 순서를 바꾸어도 같은 완료 상태에 도달한다.
- 숲닭 가축화를 수행하지 않아도 수뢰둔을 완주할 수 있다.
- 상육에서는 하나의 부분 손실이 반드시 남고 해당 대상의 복구 경로가 열린다.
- 상육 완료 뒤 체류·신뢰·관리권·공간 변화가 남고 산수몽은 자동 시작되지 않는다.
