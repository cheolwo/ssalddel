## r1 플레이어 약속과 호환 이력

다음의 초효·상효·육효 명칭은 기존 6단계 표본 설명이다. 신규 단계 수·진행 권위는 위 r2 기준을 따른다.

괘 하나는 초효부터 상효까지 이어지는 하나의 캠페인이다. 캠페인의 핵심 목적을 회복 불가능하게 잃으면 현재 효만 다시 시작하지 않고 해당 괘의 초효로 돌아간다. 이전 괘까지 확정된 영구 성과는 보존하며, 실패한 괘 안에서 얻은 임시 성과는 괘 진입 상태로 복원한다.

일반적인 부상·지연·일부 시설 파손·자원 손실은 실패가 아니라 `RecoverableSetback`이다. 보호 대상 사망이나 핵심 거점 완전 상실처럼 캠페인의 존재 이유가 사라진 경우만 `CampaignFailure`다.

## 권위 상태와 명령

- 괘 진입 시 현재 세션의 권위 상태를 `CampaignEntrySnapshot`으로 봉인한다.
- 진입 상태에는 이전 괘까지 영구 해금된 WI, 자원·관계·회복·위협, H1~H4 배치, 절기·월드 틱이 포함된다.
- 효별 WI는 현재 캠페인에서만 쓸 수 있는 임시 권한이다.
- 효 완료는 다음 효를 열지만 영구 WI 해금은 하지 않는다.
- 상효 완료는 캠페인 완주이며 현재 괘의 임시 WI와 승인된 관계·공간 변화를 영구 확정한다.
- 회복 가능한 손실은 기록하되 효 진행과 현재 상태를 유지한다.
- 회복 불가능 실패는 진입 상태 사본을 복원하고 효를 초효, 시도 번호를 다음 값으로 바꾼다.
- 실패 이력은 되돌릴 수 없는 별도 시도 원장에 남기되 NPC 관계나 복원된 세계의 서사 사실로 사용하지 않는다.

## 재도전과 결정성

- 효 순서, 핵심 인물, 필수 사건, 완료 조건은 모든 시도에서 동일하다.
- 적 위치·수량·보조 자원·경미한 환경 조건은 `ScenarioSeed + HexagramStableId + AttemptOrdinal`에서 파생한 시도 seed로 변동한다.
- 실패 전 시도에서 만든 수동 저장은 이전 시도 자료로 표시하며 현재 시도를 덮어쓰는 복원에 사용할 수 없다.
- 재도전 횟수는 제한하지 않는다.
- 반복 실패 자동 난이도 하향과 추가 보상은 이번 판본에 포함하지 않는다.

## 연출 스킵·대응 위임·캠페인 포기

- `PresentationSkip`: 대사·카메라·이미 판정된 장면을 빠르게 넘긴다. 판정 입력과 결과는 유지하며 스킵 자체로 회복·위협·관계·자원·캠페인 성패를 바꾸지 않는다. 결과 요약과 다음 선택에 필요한 핵심 정보는 남긴다.
- `ResponseDelegation`: 아직 판정되지 않은 중요한 행동을 현재 주체에게 맡긴다. 주체의 성향·이데아·관계·역량·회복·위협·활성 아르카나와 상황을 참조하므로 성공과 실패가 모두 가능하다. 무입력은 기본 관찰 정책에서 이 위임으로 이어지며 별도의 입력 실패 벌점을 붙이지 않는다.
- `ActiveCampaignAbandon`: 이미 시작된 시간 민감 캠페인에서 대응을 중단한다. 남은 위협이 계속 작용할 수 있으므로 확인 전에 예상되는 마을·거점·관리 대상 손실, 회복 가능한 setback과 `CampaignFailure` 가능성, 복원 지점을 요약한다.
- `NextCampaignDefer`: 한 괘를 완주한 뒤 다음 괘 캠페인을 시작하지 않고 자유 생활을 계속한다. 이는 포기나 실패가 아니며 시작하지 않았다는 이유로 손실을 만들지 않는다.

스토리를 즐기는 사용자와 자유 생활·자율 관찰을 선호하는 사용자는 같은 세계와 저장 기록을 사용한다. 연출을 보지 않았다는 이유로 필수 능력·관계·정보를 숨기지 않으며, 실제 사건에 참여하지 않거나 대응을 위임한 결과만 세계 상태에 반영한다.

## 턴·캠페인 변화 결산

사용자가 직접 조작했는지, 중요한 순간에만 개입했는지, 전부 맡겼는지와 관계없이 실제로 확정된 변화는 같은 원장에서 읽어 결산한다. 결산 화면을 열거나 스킵하는 행위는 새 보상·성장·손실을 만들지 않는다.

- `TurnDeltaSummary`: 턴 마감에 직전 턴 이후의 핵심 변화만 짧게 알린다. 새 이데아 노드, 숙련 변화, 중요한 재고 증감, 회복·위협 변화와 즉시 대응할 위험을 우선한다.
- `CampaignOutcomeSummary`: 괘 캠페인 마감에 진입 상태와 완료 상태를 비교해 이안이 무엇을 배우고 잃고 관계 맺었는지 전체 결산한다.
- `NextCampaignCarryover`: 다음 괘 캠페인을 시작할 때 이전 결산 중 현재 선택에 영향을 주는 변화와 미해결 위협만 다시 보여 준다. 같은 내용을 새 변화처럼 중복 기록하지 않는다.

결산은 다음 묶음을 가진다.

1. `이데아 맵`: 새로 드러난 노드, 연결된 노드, 숙련 변화와 그 근거 행동
2. `인벤토리`: 획득·소비·분실·보존 수량과 발생 사건
3. `능력·기술`: 전투 기술·벌목술·농사 등 실제 행동으로 변한 값
4. `회복·위협`: 전후 값과 변화 원인, 절기 아르카나 재방향 여부
5. `관계·약속`: 공동 행동·도움·약속 이행·실패 기록
6. `세계·관리 대상`: 마을·거점·시설·화물의 회복, 손상, 파괴 또는 미해결 상태

각 항목은 가능하면 `이전 → 현재`, 변화량, 원인 사건과 행동 기록을 함께 표시한다. 모든 변화를 회복 또는 위협으로 억지 분류하지 않는다. 예를 들어 재고 이동은 중립 변화일 수 있고 시설 파괴는 세계 상태의 손실이며, 승인된 Profile이 실제 내면 영향을 만들었을 때만 회복·위협에도 별도로 기록한다.

연출을 전부 스킵해도 `CampaignOutcomeSummary`의 핵심 변화와 다음 선택은 생략하지 않는다. 사용자는 요약 카드만 보고 닫거나 세부 원인·전체 이력을 펼쳐볼 수 있다.

`TurnDeltaSummary`의 이야기 기준 단위는 `효 턴`이다. 현재 효의 핵심 사건이 끝나면 자유 생활 구간을 열고, 사용자가 마감을 선택할 때까지 같은 효 턴에 실제 변화를 누적한다. 마감 시 진행 중 작업과 위험을 확인하고 해당 효의 이야기·자유 생활 변화를 함께 결산한 뒤 다음 효를 시작한다. 효 턴 마감은 절기 턴·WorldTick 마감을 자동 실행하지 않는다.

효 턴 마감 요청이 들어오면 이안은 현재 수행 중인 짧고 안전하게 끝낼 수 있는 동작 하나를 마친다. 장시간 작업 전체를 자동 완료하거나 새 결과를 만들지는 않는다. 다음 효의 `CurrentLocationContinuation / StagedRelocation / RequiredArrival` 계약에 따라 현재 위치에서 이어가거나, 기록된 이동 전환 뒤 목적지에서 시작하거나, 실제 도착까지 자유 생활·이동 상태를 유지한다.

효 턴 마감과 다음 효 시작은 같은 명령이 아니다. 마감 뒤에는 다음 효의 `StoryStateGate`와 `WorldStateGate`를 판정하고, 필요하면 `SpatialActivationTrigger`가 발동할 때까지 자유 생활·이동 상태를 유지한다. Collider·Trigger Volume은 발동 접점일 뿐 해금 권위가 아니며, 안정 공간 ID와 권위 상태 사본이 충족된 경우에만 진행 사건을 요청한다.

건설 H, 재고, 동행자, 권한 같은 조건은 효 기획에서 서사적 이유와 함께 명시한 경우에만 필수화한다. 부족한 조건은 숨겨진 막힘으로 만들지 않고 체크 목록으로 보여 주며, 승인된 대체 조건이 있으면 함께 제시한다. 관문을 충족하지 못했다는 사실만으로 캠페인을 실패시키지 않는다. 다만 이미 발생 중인 위협과 시간 제한은 별도 규칙에 따라 계속 진행될 수 있다.

공간 발동을 사용하는 효는 원칙적으로 `AreaSet + H1`을 함께 요구한다. AreaSet만 들어가거나 H1 표현만 가까이 보인 것으로는 충분하지 않다. 정확 H1이 아직 미정이면 기획 요구 코드와 미정 사유를 남기고 개발 준비를 완료로 올리지 않는다.

효 기획의 관문 원문은 `지금·여기·나·너·이렇게 → 결과 → 다음 선택`으로 작성한다. `지금`은 시간·현재 진행, `여기`는 공간, `나`는 행위 주체, `너`는 직접 대상, `이렇게`는 실제 행동 기록을 소유한다. 개발은 이를 기존 캠페인·세계 상태·공간 발동 검사로 투영하며 다섯 칸의 문자열만 비교해 진행시키지 않는다.

상효의 효 턴 마감은 `CampaignOutcomeSummary`로 이어지고, 이후 괘 사이 자유 생활을 연다. 이 구간에서 다음 괘 시작을 미루는 것은 `NextCampaignDefer`이며 실패가 아니다.

## 수뢰둔 기준선

- 수뢰둔은 한스 농장을 중심으로 초효부터 상육까지 끊김 없이 진행한다.
- `HansLost`, `HansFarmFullyLost`만 수뢰둔의 회복 불가능 실패 사유다.
- 울타리 일부 파손, 부상자, 지연, 일반 자원 손실은 회복 가능한 결과다.
- 완주하면 벌목·수리·순찰·조사·동물 돌봄·농장 방어 WI와 승인된 농장 변화를 영구 확정한다.
- 완주 뒤 자유 생활로 전환한다. 한스의 경비대장 소개를 수락할 때 산수몽 캠페인을 시작한다.

## 구현·검증 상한

- 이번 구현 상한은 `Logic E3`다.
- Contract, 공통 Core, LocalProcess, RemoteHost API, Save/Replay 결정성 시험을 포함한다.
- Unity Scene, Prefab, 실제 입력, Game View, 애니메이션과 Presentation E4 이상은 포함하지 않는다.
- 기존 운영 원장과 공공데이터 상태는 변경하지 않는다.
