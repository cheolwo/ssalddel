## 승인된 경험

사용자는 세계를 관찰하며 목표·운영 정책을 정한다. 직접 조작은 선택적이다. 접속 중 분신의 실제 행동은 성장할 수 있지만 미접속 중 분신은 행동하거나 성장하지 않는다. NPC는 별도 주체이며 분신의 경험치를 대신 획득하지 않는다.

사용자와 세계 안의 주체를 구분한다. 사용자는 `직접 조작`, `중요 순간에만 개입`, `전부 맡기기` 가운데 기본 관찰 정책을 선택할 수 있다. 일상은 선택한 정책 아래 계속 진행하고, 중요한 효사·캠페인 선택에서는 현재 정책에 따라 직접 선택, 선택적 미니게임 또는 주체의 자율 판단을 사용한다. 세 정책은 별도 캐릭터나 별도 저장 진행이 아니라 같은 주체의 연속된 기록이다.

- `직접 조작`: 사용자가 허용된 행동 입력을 계속 담당한다.
- `중요 순간에만 개입`: 일상은 자율 실행하고, 판본화된 중요 사건에서만 사용자에게 선택·집중 행동을 제안한다. 응답이 없을 때의 시간 정지·유예·자율 진행은 사건 Profile이 명시해야 한다.
- `전부 맡기기`: 중요 사건도 주체의 성향·이데아·관계·현재 상태와 활성 아르카나 문맥으로 판정한다. 사용자가 맡겼다는 사실만으로 유리한 결과를 만들지 않는다.

집중 미니게임은 선택적 개입 표현이다. 성공은 회복이나 알아차림의 권위 행동 기록을 만들 수 있지만 사건 성공·전투 승리·화물 보존을 직접 확정하지 않는다. 관찰 카메라 조작, 화면 열람 또는 미니게임 연출만으로 상태를 변경하지 않으며, 동일 사건 재시도로 보상을 중복 획득하지 않는다.

참여 시점과 개입 표현은 서로 다른 설정이다. `중요 순간에만 개입`을 선택한 사용자도 그 순간을 짧은 미니게임으로 처리하거나 현장 실시간 조작으로 전환할 수 있다. `계속 직접 참여`를 선택해도 접근성·피로도 설정에 따라 일부 반복 판정을 간편 미니게임에 맡길 수 있다. 효사마다 지원 조합, 공유하는 필수 이야기 결과, 방식별로 달라질 수 있는 숙련·손실·관계·정보를 기획서에 기록한다.

관찰을 신규 이야기 장면의 기본값으로 삼는다. 중요한 개입 가능 순간에는 짧은 입력 표시를 보여 주고, `Space` 또는 사건 Profile이 허용한 마우스 입력으로 개입을 시작할 수 있다. 아무 입력도 없으면 화면 실패로 처리하지 않고 이안의 자율 행동과 이야기 판정을 계속한다. 개입 뒤 간편 미니게임과 현장 직접 조작 가운데 무엇을 열지는 장면이 지원하는 범위와 사용자 기본 설정을 따른다. 정확 키는 접근성 재지정이 가능해야 하며 이 문서의 예시 키를 저장 계약으로 고정하지 않는다.

`연출 스킵`, `대응 위임`, `진행 중 사건 포기`를 구분한다. 연출 스킵은 이미 판정된 장면을 빨리 넘기는 표시 기능이므로 추가 손실을 만들지 않는다. 대응 위임은 아직 판정되지 않은 행동을 이안에게 맡기므로 현재 상태에 따라 성공·실패할 수 있다. 진행 중 사건 포기는 남은 위기와 보호 대상을 방치할 수 있으므로 예상 손실·복원 지점·캠페인 실패 가능성을 보여 주고 별도 확인한다.

관찰 결과는 턴 마감의 짧은 변화 알림과 캠페인 마감의 전체 결산으로 나눈다. 이데아 맵·인벤토리·능력·회복·위협·관계·세계 상태의 실제 전후 차이를 같은 revision에서 읽고, 중요한 변화부터 카드로 보여 준다. 사용자가 관찰만 했거나 연출을 스킵했어도 확정된 결과는 숨기지 않는다. 요약 열람 자체가 새 상태를 만들거나 자율 실행 결과를 재판정하지 않는다.

개인별 독립 세계에서 가상의 창고 입고·검수·적치를 첫 표본으로 사용한다. Farm 출하·도시 배송을 시작 조건으로 요구하지 않는다. 실제 업무 저장소나 실제 주문·결제·운송 효과는 만들지 않는다.

날씨·환경·농산물 가격은 기존 수집/읽기 전용 조회를 통해 표현과 정보에만 반영한다. 출처·지역·단위·기준 시각을 표시하며 데이터 부족을 가상 실제값으로 숨기지 않는다. 첫 판본에서는 재고·수익·작업 속도를 변경하지 않는다.

## 개인과 세계의 시간

- 서버가 세계 시간과 접속 상태를 소유한다. 사용자 입력이 없어도 살아 있는 연결은 접속으로 인정한다.
- 접속 종료 뒤 개인에게 귀속되는 NPC 생산·수익은 실제 시간 24시간까지만 인정한다. 이후 해당 자원 소비 작업도 대기한다. 세계 공통 NPC 생활은 별개로 계속된다.
- 상한을 가로지르는 작업은 전체 경과 시간에 보상을 곱하지 않고 허용 시간 구간만 소비한다. 상한 이후 폐기 생산이나 재료만 소모하는 처리는 금지한다.
- 재접속 전에 미접속 구간을 정산하고 새 접속 상태를 적용한다. 종료 통지를 반복해 누적 기한을 연장하지 않는다.
- 동일 시각 재시도는 추가 진행이 없다. 이전 시각 요청은 거부한다. 입력 시각은 신뢰할 수 있는 서버 시계만 공급한다.
- 자동 실행은 기본 비활성이다. 구형 저장에는 관찰 정책을 자동 생성하거나 적용하지 않는다.

## 구현 순서와 대체 관계

1. P0: 이 기획·목차·인계 명세를 등록한다. 기존 기획의 직접 체험 선행은 관찰 프로필에 강제하지 않으며 구형 시나리오 의미는 보존한다.
2. P1: 접속·제어권·시간 정산 정책을 시험한다. 이어 세계 소유권·내구 저장·서버 실행기·개인 효과 분류를 실제 세션에 결속한다.
3. P2: 기존 NPC 입고/검수/적치 규칙에 재현 가능한 가상 화물 생성과 허용 정책을 연결한다. LLM은 필수가 아니다.
4. P3: 기준 Scene의 관찰 카메라·NPC 표현과 변화 요약을 연결한다. 제어권을 넘길 때 진행 중 작업의 중복 실행을 막는다.
5. P4: 현실 자료를 관찰 정보로 연결한다. 공급자·지역·품목·권리는 별도 수집 작업에서 확인한다.

H/E 번호 자체를 재정의하지 않는다. 관찰 프로필의 E7은 정책 선택→자율 행동→결과 판독→다음 선택을 실제 화면에서 검증한다. 수동 조작 WI의 기존 증거를 관찰 WI 증거로 재사용하지 않는다.

## 인계와 미정

정확한 지속 실행 주기, 접속 임대/다중 연결 계약, 장기 시나리오 기간, 중도 작업 정산과 개인 자원 소유권 분류를 기존 Core에 결속하기 전 지속 실행을 켜지 않는다. 중요 사건의 시간 정지·유예·무응답 처리, 첫 집중 미니게임과 회복량도 사건 기획에서 정해야 한다. 공간/시각 연구는 기존 창고 후보와 승인 판본을 재결속한 뒤 진행한다. 이 문서 등록 자체는 WI·Goal 자동 활성화나 E 승격이 아니다.
