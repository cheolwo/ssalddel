승인 기획: [축소하지 않는 동네 관찰 맵 r3](observer-map.r3.md), SHA256 `A7F0F4F5E456883FCC255188C8B60F88C5D04622954F70CF13CB9F4E4865D6DD`. 승인 근거는 사용자의 맵 유지·확장 요청, Required 공간 기준선은 같은 문서의 `Accepted 공간 기준선`이다. 범위가 달라지면 이 명세와 기획 판본을 다시 결속한다.

## 주체·결과·회복

기존 [r2 업무 API 명세](observer-api-work.r2.md)의 음식점·주문자·기사 두 명과 이동 WI 조회를 그대로 사용한다. 신규 주체·WI·Goal을 만들지 않는 표현 회귀 보완이다. 관찰자는 동네 전체를 보고 역할 카드를 선택하며 휴대폰을 닫아 넓게 볼 수 있다. 배경 건물은 선택 가능한 서버 주체나 새로운 배달 목적지가 아니다. 기존 완료 주문에서는 기사가 정지해 있는 것이 정상이다.

서버 실패는 미연결/오래된 조회로 남기며 배경 확장으로 성공·위치를 합성하지 않는다. 작은 화면에서는 전체 맞춤 때문에 NPC가 작아질 수 있으므로 기존 역할 카드가 선택 경로다. 저장 없이 원래 프로필로 돌아갈 수 있어야 한다.

## 담당·쓰기·검증 상한

정확 쓰기 경로는 [기획의 경로 목록](observer-map.r3.md#정확-쓰기-경로)을 따른다. root는 Hongdal 문서, 기존 `world_phone_validation` 담당은 Unity 코드·시험·View 캡처를 소유한다. 기존 dirty 변경을 patch 직전 다시 확인하고 최소 결합한다. 새 코드의 안정 ID/DTO/API는 변경하지 않는다.

검증은 소스 diff, 실제 Unity 컴파일, 집중 EditMode, 제한적인 실제 Play Mode/Game View, 기존 완료 GET 판본 비교로 구분한다. 새 주문 POST·서버 5분 재실행·DB 쓰기·원래 슬롯 저장/리셋은 포함하지 않는다. 캡처/결과는 [r3 결과](observer-map-result.r3.md)에 결속하며 실제 증거가 없으면 미검증으로 남긴다. 기존 전체 회귀 실패와 저장 지연을 이 작업의 통과로 가리지 않는다. Scene 저장·commit·push·E 자동 승격 없음.
