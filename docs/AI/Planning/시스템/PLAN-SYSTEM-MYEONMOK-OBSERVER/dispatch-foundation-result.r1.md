## 구현

- 기존 `음식배달픽업평가Policy.판정` 호출과 정렬을 보존하고 차량·보행 합산 소요분을 받는 `예상소요시간판정`을 추가했다. 운영 시계·외부 경로를 조회하지 않는다.
- `음식배달후보선정Policy`는 가용성·위치 신선도·경로 존재·접근 반경을 검사하고 동일권→인접권→후보0일 때 제한 확장 순서로 후보를 선정한다. 적격 후보는 기존 픽업창·시간 차이·권역·점수·거리·ID 순으로 정렬한다. 선택 기사와 각 제외 사유를 반환한다.
- `이동자원점유Policy`는 최초 대기 Tick→기사 ID 순으로 방향 중립 도로·출입구 자원 묶음의 진입 후보를 원자적으로 판정한다. 부분 점유·기존 점유 상태에서의 추가 자원 요청을 차단하고 선행 대기와 겹치는 자원에 대한 추월을 막는다. 서로 독립된 자원은 같은 계산에서 허용할 수 있다.
- 입력 객체를 변경하지 않고 읽기 전용 결과를 반환한다. 실제 점유 확정·해제·이동은 수행하지 않는다. 입력의 기사 ID·거리·시간·중복 요청을 검사한다.
