상태: Approved. 근거: 2026-09-07 기사3명·기존 정렬 유지 계획 구현 요청, 도로/출입구 점유 대기 승인, 다음 우선순위 진행 요청. [Accepted 공간 기준](synthetic-spatial-study.r2.md)을 적용한다. 기존 WI-CITY-SYNTHETIC-ASSIGN/MOVE/PICKUP/RETURN의 지원 계산만 다루며 기존 r1 실행·저장·기획 hash는 바꾸지 않는다.

## 주체·결과·경계

배차 규칙이 가상 기사 후보를 평가하고, 공간 규칙이 기사별 진입 요청에서 점유 후보를 반환한다. 주체 ID는 호출자가 제공하는 기존 NPC 안정 ID다. 직접 결과는 선택 후보/제외 사유와 승인 가능한 점유 요청이다. 확정·원장·이동·권위 revision 변경은 하지 않는다. 실패는 후보 없음/자원 점유/선행 대기이며 다음 Tick 같은 상태 사본으로 재평가한다.

기존 시각 기반 픽업 평가를 유지하면서 차량+보행 예상 소요분을 받는 함수를 추가한다. 후보는 유효성·경로·접근 반경으로 제외 후 동일권 후보가 최소수 미만이면 인접권을 추가하고, 후보0일 때만 제한 확장한다. 공통 기존 정렬을 그대로 사용한다.

점유는 물리 구간의 방향 중립 ID와 출입구 ID를 사용한다. 여러 충돌 자원이 필요한 요청은 전부 가용할 때만 원자적으로 후보 승인한다. 기존 점유자가 새 자원을 추가 요청하는 hold-and-wait는 허용하지 않는다. 대기는 최초 요청 Tick→기사 ID 순서, 선행 요청과 겹치는 자원에는 추월을 허용하지 않는다. 실제 대기 위치·교차점·점유 해제·Session 저장 연결은 다음 구현 책임이다.
