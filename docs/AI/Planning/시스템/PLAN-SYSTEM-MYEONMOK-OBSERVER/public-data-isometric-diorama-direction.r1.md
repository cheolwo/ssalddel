# 공공데이터 기반 아이소메트릭 3D 디오라마 표현 방향 r1

- 기획 ID: `PLAN-SYSTEM-MYEONMOK-OBSERVER`
- 상태: `ApprovedDirection / FiveElementObjectCatalogFoundationImplemented / UnityExecutionDeferred`
- 승인 근거: 2026-09-08 사용자가 Graph Map·배치 Map으로 자료의 쓰임을 먼저 정한 뒤 Unity에서는 공공데이터 기반 아이소메트릭 3D 디오라마 표현을 지향하도록 요청했다.
- 적용 범위: 사가정역 중심 1km 관찰 구역을 첫 기준으로 삼는다. 면목동 전체 36개 타일 고도화나 실제 World 배치 승격을 뜻하지 않는다.

## 표현 목표

Unity 지도는 위에서 비스듬히 내려다보는 3/4 아이소메트릭 구도의 저폴리 3D 디오라마를 지향한다. 도로는 얇은 면, 건물은 외곽선을 단순 돌출한 덩어리, 공원·시설·업무 장소는 작은 표식과 색상 오버레이로 표현한다. 공공데이터의 관계와 상대적 위치를 한눈에 관찰하는 것이 우선이며 실사 도시 복원이나 정밀 내비게이션을 첫 목표로 삼지 않는다.

기본 지리층은 저채도 도로·건물·녹지로 유지한다. 음식점·주택·창고·배송 기사처럼 게임 안에서 의미가 부여된 대상만 오행 색상과 상태 표식을 별도 오버레이로 사용한다. 공공자료에 있는 건물이라는 이유만으로 음식점·주택·창고 같은 업무 역할을 부여하지 않는다.

거리에 따른 판독 수준은 다음을 지향한다.

| 관찰 거리 | 우선 표현 | 표시하지 않는 것 |
| --- | --- | --- |
| 원거리 | 500m 타일, 주요 도로, 100m 단위 자료 밀도 | 개별 주소·사업체명·출입구 |
| 중거리 | 단순 건물 덩어리, 도로망, 시설 종류별 집계 표식 | 입주·현재 영업·통행 가능성 확정 |
| 근거리 | 검증된 건물 외곽선, 근거가 구분된 높이, 선택 정보 | 임의 층수·동호수·출입구·실내 |

도로 폭과 자료가 없는 건물 높이를 화면 판독용 기호로 사용할 때는 실제 폭·높이와 구분해 표시한다. 미확인 값을 현실 사실로 승격하거나 빈 공간을 실제 공터로 단정하지 않는다.

## Graph Map·배치 Map·Unity의 관계

```text
공공데이터 동결 사본
    ↓ 출처·판본·hash·품질 확인
Graph Map
    ↓ 지역·자료층·시설 후보·시나리오의 의미 관계
배치 Map
    ↓ 기준 원점·타일·좌표·외곽·집계·미배치 사유
개인정보를 제거한 Unity용 관점별 조회 결과
    ↓ 읽기 전용 소비
SimulationWorldShell의 아이소메트릭 3D 디오라마
```

Graph Map은 `ContainsReferenceArea`, `HasReferenceLayer`, `ScenarioOverlayOf`처럼 무엇이 무엇과 관련되는지 소유한다. 배치 Map은 500m 타일, 사가정역 ENU 기준 좌표, 도로 선분, 건물 외곽과 자료별 집계를 소유한다. Unity는 이 결과를 보여줄 뿐 관계·좌표·업무 상태를 새로 확정하지 않는다.

기존 도형 동네는 삭제하지 않고 `ScenarioOverlayOf`로 분리된 가상 시나리오층으로 유지한다. 현실 지리 기본층 위에 판타지·운영 표현을 얹을 수 있지만, 이 결합 때문에 합성 건물이나 NPC 경로가 실제 면목동 시설·도로로 승격되지는 않는다.

## 자료 공개와 권위 경계

- Unity 배포 자원에는 공개·재배포 가능한 도로·건물 외곽과 비식별 집계만 넣는다.
- 개별 상호명, 상세 주소, 동·호수와 비공개 검토 행은 로컬 검토 자료에 남기고 게임 자원에 복제하지 않는다.
- 좌표계·현재 영업·입주·출입구가 확인되지 않은 자료는 강제 배치하지 않고 집계 또는 보류 사유로 표현한다.
- Unity 실행 중 외부 공공데이터 제공자나 운영 DB를 직접 호출하지 않는다. 검증된 동결 상태 사본을 읽기 전용으로 소비한다.
- 카메라 이동·선택·정보창·LOD 전환은 표현 동작이다. NPC, 주문, 재고, 배차, 이동과 저장 상태의 최종 결정 권한을 갖지 않는다.
- 공식 Scene은 `SimulationWorldShell` 하나를 유지하며 이 방향을 이유로 새 지도 Scene이나 별도 Map Manager를 만들지 않는다.

## 현 단계와 다음 관문

현재 사가정 OSM 참고 자료의 건물 602개와 도로 선분 2,397개는 공간 참고 후보이며, 배치 Map은 `PlacementReviewOnly / SceneReady=false`다. 이 문서는 표현 방향을 확정하지만 Unity 코드·Scene·Prefab·카메라·LOD를 변경하거나 실제 Play Mode 검증을 수행한 근거가 아니다.

2026-09-09 [면목동 오행 업무 객체 대장 r1](myeonmok-five-element-game-object-catalog.r1.md)에서 Graph Map·배치 Map·Geometry·WI 분류의 판본과 hash를 대조하고, 사가정 1km의 비식별 객체 원형과 중립 배경 후보를 Mongo 읽기 전용 묶음으로 준비했다. 이 준비는 Unity 코드·Scene 적용이 아니다. 후속 Unity 구현은 해당 동결 묶음을 검증한 뒤 기존 도형 지도에 단계적으로 연결하며, 첫 구현에서도 1인칭 전투, Actor 순간이동, 임의 출입구와 길찾기는 제외한다.
