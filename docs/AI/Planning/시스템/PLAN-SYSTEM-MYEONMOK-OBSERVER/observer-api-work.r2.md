## 검증 상한

단위·HTTP·DB·Event 재처리·Unity 컴파일·EditMode·실제 5분 Game View를 별도로 기록한다. DB 현재 모델로 생성한 격리 스키마는 운영 migration 검증이 아니다. 수령 완료와 5분 제한은 별개이며 5분까지 미완료이면 TimedOut으로 종료한다. 기존 저장 성능은 누적 표본 저장 1회로 재확인하고 서버 DB 증거와 섞지 않는다. 결과가 없는 E는 미검증, 자동 E 승격·운영 공개·commit·push 없음.
