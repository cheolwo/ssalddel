# 살뜰마트 배송센터 — 구현 결과 r3

[기획·공간 기준·명세](mart-center.r3.md)

## 실행

Unity 메뉴 **Ssalddel → 실행 프로필 → 살뜰마트 피킹·포장·배송**을 선택하고 기존 `SimulationWorldShell`에서 Play 후 재생한다. r3 전용 저장 슬롯 `synthetic-delivery-r3-primary`를 사용하며 r1/r2 저장을 덮지 않는다. 재생 중 매 Tick 저장하고 중지 시간은 따라잡지 않는다. 365초가 끝나면 새 표본으로 초기 재고를 복구할 수 있다.

## 연결된 흐름

- 음식점 빨강, 주문자 주택 파랑, 살뜰마트·내부 작업자 하양, 기사·차량 검정. 기사 번호는 밝은 글자이며 상태를 나타내려고 역할 색상을 바꾸지 않는다.
- 기존 마트를 지붕 없는 적재대2개·포장대·인계대 공간으로 확장했다. 물건은 재고→작업자→인계대→기사 순서로 표시한다.
- 작업자1명이 주문별 두 상품을 원자적으로 예약하고 적재대 이동→피킹→포장→인계대 이동을 수행한다. 포장·적치 완료 후에만 배차 후보가 된다.
- 음식점 주문2건과 마트 주문3건을 함께 관찰한다. 마트 초기 재고는 상품별2개이므로 2건은 배송하고 마지막1건은 재고 부족으로 대기한다. 대기 중 무한 주문·무료 재입고는 없다.
- 음식점/마트 원장은 분리하고 배차 평가·도로 점유·이동·배송·복귀를 공유한다. 마트 운송을 음식 조리 주문으로 위장하지 않는다.
- 서버 출고·피킹·포장 완료 후 배차 대기의 **업무 의미**를 대조했다. DB 의존 OutboundBatchEngine/창고 서비스 전체를 이식한 것이 아니며, 기존 공통 기사 평가·점유 Policy를 실제 재사용했다. 창고 여러 곳의 선택·분할 출고·운영 DB 효과는 제외한다.
