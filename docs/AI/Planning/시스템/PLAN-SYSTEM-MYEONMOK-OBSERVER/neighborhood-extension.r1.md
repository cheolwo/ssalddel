# 같은 도형 동네의 좌표 참고 확장 r1

- 사용자 승인: 2026-09-08 현재 대화. 기존 도형 동네를 보존하고 실제 좌표를 참고하여 최대 1km 구역을 점진 확장한다.
- 기존 `neighborhood-maps.r1.md`의 후속 표현 범위. 새 업무 WI·Scene·저장 모드를 만들지 않는다.
- 기존 배달 WI의 논리 E1~E7은 변경하지 않는다. 표현 E1~E4는 시장 좌표 세 곳의 근거·정밀도·지역 좌표 변환과 참고 표식을 준비한다. E5~E7은 실제 World 배치·관찰·저장 회귀가 확인될 때 별도 판단한다.
- 기존 도형 동네의 좌표·작업점·경로를 보존하고 동쪽에 1km×1km 자료 참고 구역을 붙인다. 원점은 면목시장 원천 좌표이며 WGS84 타원체의 ECEF→ENU로 동서·남북 상대 거리를 계산한다. 이는 EPSG:5186 도로 검사 입력이 아니다.
- 시장 세 곳은 출처를 가진 위치 표식이다. 시장 외곽·층수·출입구·실제 접근로가 확보될 때 해당 표식을 같은 ID로 상세화한다. 미확정 도로를 생성하지 않는다.
- 기존 프로필5의 같은 동네에서 확장 개요와 동네 집중을 전환한다. 기본 초점은 기존 동네다. 이전 실행 메뉴는 실험 하위 목록에 보존한다.
- 검증: 원점·방향·거리·범위·잘못된 좌표·중복 거부, 원본 hash와 세 행 재대조, 기존 맵 생성·회귀, 소비 코드 컴파일. Scene 저장 및 실제 화면 판독은 별도 결과로 기록한다.

## 구현 결과

- `neighborhood-market-extension.v1.json`에 원본 hash·기준일·원점·세 시장 좌표를 동결했다. 원장 `PendingHumanReview`와 `source-point-unverified`는 유지한다.
- 기존 `manage-neighborhood-maps.ps1`이 기존 배치 정의와 함께 확장 좌표를 공통 C#으로 생성한다. 별도 Scene·실행 프로필·Map Manager는 추가하지 않았다.
- 1km×1km 구역 중심은 기존 동네 좌표 `(550, 8)`이다. 기존 동네와 맞닿지 않도록 동쪽에 붙였으며 이 평행이동은 게임 배치 결정이다. 구역 내부는 1 Unity 단위=1m의 실제 상대 거리다. 기존 합성 동네 자체가 실제 면목시장 주변이라는 의미는 아니다.
- 세 시장은 8×8×4 크기의 **기호용 위치 표식**이다. 이 크기는 실측 건물 치수가 아니며 현실 시설·NPC 업무·출입구·배달 경로로 등록하지 않는다. 시장 간 실제 방향과 거리는 유지하고 건물 외곽 및 연결 도로는 후속 자료로 확장한다.
- Unity 프로필5의 `BuildNeighborhoodLife`에서 같은 Root에 확장 바닥과 위치 표식을 조립한다. 기존 동네 집중을 기본값으로 유지하며 좌하단 `같은 동네 · 1km 확장 보기` / `기존 동네 집중` 버튼으로 관찰 범위를 바꾼다. 확대 개요에서 카메라 거리와 원거리 절단면을 함께 맞춘다.
- 진입: `Ssalddel → 동네 관찰 → 기본 동네 · NPC 생활과 확장` 선택 후 기존 `SimulationWorldShell`에서 Play. 기존 30분 생활 상한을 그대로 사용하며 5분 검증 메뉴는 업무 서버 항목이다. 이전 세부 프로필은 `이전 실험` 아래로 옮겼다. 다른 전문 도구의 메뉴는 유지한다.
- 자동 검사: 좌표/거부/원본 대조 13건, 기존 맵 정상 및 오류 주입 8종 통과. Contracts 빌드 경고0/오류0, Unity 컴파일 및 기존 저장·복원 EditMode 1/1 통과 (`artifacts/local/validation/neighborhood-extension-unity.xml`).
- Pipeline 연결 인스턴스가 없어 CLI EditMode를 사용했다. 실제 Play Mode·Game View의 글자 크기·버튼 겹침·시야·Scene 저장은 미검증이며 E 승격·DB 쓰기·commit·push 없음.
- 범위 Fast 공백 검사 통과. 전체 Task는 Simulation/Unity 코드 지도 검사 후 E 책임 코드 지도 생성물 불일치로 중단됐다 (`artifacts/local/validation/20260908-180118/evidence-map-check.log`). 전체 build/test 통과를 주장하지 않으며 공용 생성물을 이 작업에서 일괄 재생성하지 않았다.
